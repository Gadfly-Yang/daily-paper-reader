## 摘要
人脸伪造内容在 Web 上的迅速传播对视觉内容的可信度构成了挑战。在实际 Web 环境中，被篡改的媒体源自不断演化的生成流程，并在传播过程中经历多样化处理，这使得在未见过的操纵方式和视觉变化下进行可靠的真实性评估成为一项关键挑战。我们观察到，标准的经 LoRA 适配的 CLIP 检测器表现出不均匀的 patch 级决策依赖，将不成比例的类别特定相关性集中于一小部分视觉 patch 上。为提高对此类高度依赖证据变化的鲁棒性，我们提出 EviStress，一个用于可泛化人脸伪造检测并带文本解释的两阶段框架。在第一阶段，证据定向 patch 扰动（Evidence-Targeted Patch Perturbation, ETPP）从全局、关系和语义线索估计 patch 依赖，并分配正相关的扰动概率，在训练期间对高度依赖的视觉证据进行显式压力测试。我们进一步引入判别性变异保持（Discriminative Variation Preservation, DVP），约束干净表示与扰动表示之间的残差，以保留真实性判别信息。在第二阶段，内在证据指令微调（Intrinsic Evidence Instruction Tuning, IEIT）将适配后的 CLIP 编码器迁移到 LLaVA 中作为其视觉塔，并进行参数高效的多模态指令微调，从而无需外部检测器，直接基于学到的伪造敏感表示实现真实性预测和文本解释。实验表明，该方法提升了跨数据集和跨方法的泛化能力以及损坏鲁棒性，同时多模态模型能够提供真实性预测和人类可读的解释。

## Abstract
The rapid spread of face forgeries on the Web challenges the credibility of visual content. In practical Web environments, manipulated media originate from evolving generation pipelines and undergo diverse processing during dissemination, making reliable authenticity assessment under unseen manipulations and visual changes a critical challenge. We observe that a standard LoRA-adapted CLIP detector exhibits uneven patch-level decision dependence, concen trating a disproportionate share of class-specific relevance on a small fraction of visual patches. To improve robustness to variations in such highly dependent evidence, we propose EviStress, a two-stage framework for generalizable face forgery detection with textual explanations. In the first stage, Evidence-Targeted Patch Perturbation (ETPP) estimates patch dependence from global, relational, and semantic cues and assigns positively correlated perturbation probabilities, explicitly stress-testing highly dependent visual evidence during training. We further introduce Discriminative Variation Preservation (DVP), which constrains the residual between clean and perturbed representations to retain authenticity discriminative information. In the second stage, Intrinsic Evidence Instruction Tuning (IEIT) transfers the adapted CLIP encoder into LLaVA as its vision tower and performs parameter-efficient multimodal instruction tuning, enabling authenticity prediction and textual explanation directly from the learned forgery-sensitive representation without an external detector. Experiments demonstrate improved cross-dataset and cross-method generalization and corruption robustness, with the multimodal model providing authenticity predictions and human-readable explanations.

## 2. 方法论

### 2.1 总体框架
- 两阶段：**Stage 1 视觉调优**（ETPP + DVP）→ **Stage 2 内在证据指令微调 IEIT**（把适配后的 CLIP 编码器接入 LLaVA）。
- ETPP 与 DVP **仅在训练期生效，推理时无额外模块**。

### 2.2 Evidence-Targeted Patch Perturbation（ETPP）
- 视觉编码器 V_θ 含 L 个 Transformer block，第 l 块输出 token 序列 X^(l) = [x_cls^(l), x_1^(l), …, x_N^(l)]，x_i ∈ R^d。
- 仅对**前 K 个 block**（K ≤ L，控制扰动深度）施加扰动；CLS/全局 token 不改动，l > K 的块不扰动。
- 每个 patch 得到归一化依赖分数 s_i^(l) ∈ [0,1]，线性映射为扰动概率：**p_i = p_min + s_i(p_max − p_min)，p_min = 0.45，p_max = 0.95**（依赖越强、被扰动越频繁）。
- 采样二值指示 m_i ~ Bernoulli(p_i) 与乘性因子 ε_i ~ N(1, δ²)，扰动 token 为
  **x̃_i = [(1 − m_i) + m_i·ε_i]·x_i（l ≤ K）**。
- 因高斯因子以 1 为中心，扰动引入的是**受控特征变化**而非确定性地压制被选中的证据。

### 2.3 Patch Dependence Estimation（三线索依赖估计）
- **全局线索**：u_i^g = sim(x_i, x_cls)，衡量局部 patch 与图像级表示的契合度。
- **关系线索**：u_i^r = 与其他所有 patch 的平均余弦相似度（捕捉 patch 间结构一致性）。
- **语义线索**：u_i^s = |sim(x_i, t_f) − sim(x_i, t_r)|，t_r/t_f 为由冻结文本编码器与 "a real face"/"a forged face" 提示得到的真实/伪造文本原型。
- 三线索各自在 patch 维度独立归一化后**等权聚合**：s_i = (1/3)(û_i^g + û_i^r + û_i^s)。

### 2.4 Discriminative Variation Preservation（DVP）
- 得到干净表示 z_c 与扰动表示 z_p 后构造归一化残差：**z_r = z_c − z_p，ẑ_r = z_r / (‖z_r‖₂ + ε)**。
- 让残差与真实/伪造文本原型对齐，计算类别 logits **ℓ_k^r = ẑ_rᵀ t_k / τ**，并以交叉熵监督 **L_dvp = −log [exp(ℓ_y^r) / Σ_k exp(ℓ_k^r)]**。
- 目的：避免残差退化为任意噪声，同时**不直接最小化干净/扰动表示差异**（否则会抵消 ETPP 的压测效果）。
- 总损失：**L_stage1 = L_cls + λ_dvp · L_dvp，λ_dvp = 0.2**。

### 2.5 Intrinsic Evidence Instruction Tuning（IEIT）
- 用 Stage 1 的 LoRA-CLIP 编码器**替换 LLaVA 原视觉塔并冻结**；多模态输入 **H_i = [P_φ(V_θ(I_i)); E(q_i)]**，P_φ 为多模态投影器。
- 自回归指令微调损失只作用于助手回复 token：**L_ieit = −(1/M) Σ_i Σ_t log p_Θ(a_{i,t} | a_{i,<t}, q_i, I_i)**。
- 仅优化**多模态投影器**与**语言模型 LoRA** 参数，视觉编码器冻结以保留伪造敏感表示。
- 推理时 MLLM 直接输出统一的"真伪判定 + 文本解释"，**无需外部检测器**。
