## 摘要
现有的可解释深度伪造取证方法通常依赖任务适配的多模态大语言模型（MLLM）联合完成检测、定位与解释。受智能体式工具使用方式的启发，我们提出一种感知即工具（Perception-as-Tool）范式并将其实例化为 PATE-Forensics，在架构上将检测与定位同解释生成解耦，同时在取证感知工具内部尽可能紧密地耦合检测与定位。基于 DINOv3 的工具将多粒度检测模块与线索引导的定位模块相结合：多粒度检测模块整合全局、图像块级和分割级证据；线索引导定位模块将图像块级和分割级证据空间化为伪造分数图，以指导密集掩码预测。原始图像和该工具产生的取证感知输出构成结构化取证上下文，供通用 MLLM 在提示约束下生成解释，无需任务特定微调。在 DDL-X Track 3 上，PATE-Forensics 取得最佳官方分数 0.89，比第二名高出 0.19 分。代码见 https://github.com/yqli00000/PATE-Forensics。

## Abstract
Existing explainable deepfake forensic methods typically rely on task-adapted MLLM to jointly address detection, localization, and explanation. Inspired by agent-style tool use, we instead introduce a Perception-as-Tool paradigm and instantiate it as PATE-Forensics, which architecturally decouples detection and localization from explanation generation while coupling detection and localization as tightly as possible within a forensic perception tool. The DINOv3-based tool couples a multi-granularity detection module that integrates global, patch-level, and segment-level evidence with a cue-guided localization module by spatializing the patch-level and segment-level evidence into forgery score maps that guide dense mask prediction. The original image and forensic perception outputs produced by the tool form structured forensic context for a general-purpose MLLM, which is guided by prompt constraints to generate explanations without task-specific fine-tuning. On DDL-X Track 3, PATE-Forensics achieves the best official score of 0.89, outperforming the second-ranked team by 0.19 points. Our code is available at https://github.com/yqli00000/PATE-Forensics.

## 1. 论文的核心问题与整体含义

- **研究背景**：深度伪造图像检测不仅需要判断“真 / 假”，还需要定位被篡改区域，并以人类可读的方式解释判断依据。现有可解释取证方法通常将检测、定位、解释三项任务交给经过任务适配微调的多模态大语言模型（MLLM）联合完成。
- **核心问题**：任务适配 MLLM 需要针对特定取证任务或数据反复微调，成本高、可扩展性差；同时细粒度取证感知仍然依赖局部伪影、纹理不一致等密集视觉线索，而通用 MLLM 未必擅长直接从原始图像中稳定提取这些线索。
- **整体含义**：论文提出“感知即工具”（Perception-as-Tool）范式，将检测与定位封装为专用取证感知工具，只让通用 MLLM 基于工具输出的结构化上下文生成解释，从而在架构上解耦“感知”与“解释”，避免对 MLLM 进行任务特定微调。

## 2. 论文提出的方法论

### 2.1 总体框架

- 系统由两部分组成：
  1. **取证感知工具**：基于 DINOv3，负责图像级真伪检测与篡改区域定位。
  2. **通用 MLLM 解释模块**：接收原图 + 工具输出的结构化取证上下文，通过提示约束生成解释，不进行任务特定微调。

### 2.2 多粒度伪造检测

- 使用 DINOv3-L/16 作为骨干，并通过 LoRA 进行轻量适配。
- 检测模块整合三类证据：
  - **全局证据**：使用 DINOv3 class token 的归一化表示，并通过轻量分类器产生辅助真伪 logit：
    \[
    \ell^{\text{img}}_g = C_g(\text{LN}(z_{\text{cls}}))
    \]
  - **图像块级证据**：对每个 patch token \(x_i\) 通过 MLP \(f_p\) 预测可疑度 logit \(a_i\)；再通过温度缩放的 softmax 权重聚合成图像级表示 \(p_{\text{agg}}\)，并得到辅助真伪 logit：
    \[
    w_i = \frac{\exp(a_i/\tau)}{\sum_{j=1}^N \exp(a_j/\tau)},\quad
    p_{\text{agg}} = \sum_{i=1}^N w_i x_i
    \]
    \[
    \ell^{\text{img}}_p = C_p(\text{LN}(p_{\text{agg}}))
    \]
    同时将 patch logits 空间化为伪造分数图：
    \[
    S_p = \sigma(\text{reshape}(a))
    \]
  - **分割级证据**：在冻结的 DINOv3 patch token 上做凝聚聚类，得到 patch 到 segment 的分配 \(r_i \in \{1,\dots,K\}\)；将分配应用到 LoRA 适配后的 token 上，计算每个 segment 原型：
    \[
    q_k = \frac{1}{|R_k|}\sum_{i\in R_k} x_i,\quad R_k = \{i \mid r_i = k\}
    \]
    通过 MLP \(f_s\) 预测 segment 可疑度 logit \(b_k\)，温度加权聚合成 \(s_{\text{agg}}\)，并得到 segment 分数图：
    \[
    S_s(i) = \sigma(b_{r_i})
    \]
- **主检测结果**：将全局、patch、segment 三类表示归一化后拼接，送入主分类器：
  \[
  \ell_m = C_m([\text{LN}(z_{\text{cls}});\text{LN}(p_{\text{agg}});\text{LN}(s_{\text{agg}})])
  \]

### 2.3 线索引导定位

- 将 patch 分数图 \(S_p\) 与 segment 分数图 \(S_s\) 拼接为二通道引导图：
  \[
  S = \text{concat}(S_p, S_s)
  \]
- 从 DINOv3 第 6、12、18、24 层提取多尺度特征 \(F_1,\dots,F_4\)，与引导图一起投影并融合：
  \[
  F_{\text{merge}} = \text{Concat}(\phi_1(F_1),\dots,\phi_4(F_4),\phi_s(S))
  \]
- 使用轻量 SegFormer 风格解码器生成密集掩码：
  \[
  \hat{M} = \sigma(\text{Up}(\psi(F_{\text{merge}})))
  \]
- 这样定位模块不是独立工作，而是显式复用检测阶段的 patch / segment 可疑度图作为粗粒度伪造线索。

### 2.4 训练目标

- 总损失：
  \[
  \mathcal{L} = \mathcal{L}_{\text{det}} + \mathcal{L}_{\text{cues}} + \mathcal{L}_{\text{mask}}
  \]
- **检测损失**：主 logit 与三个辅助 logit 均用真伪标签监督：
  \[
  \mathcal{L}_{\text{det}} = \mathcal{L}_{\text{cls}}(\ell_m,y) + \mathcal{L}_{\text{cls}}(\ell^{\text{img}}_g,y) + \mathcal{L}_{\text{cls}}(\ell^{\text{img}}_p,y) + \mathcal{L}_{\text{cls}}(\ell^{\text{img}}_s,y)
  \]
- **线索损失**：用 ground-truth 掩码下采样得到 patch 级目标 \(M_p\) 和 segment 级目标 \(M_s\)，监督 patch / segment 可疑度 logit。
- **掩码损失**：二元交叉熵 + Dice loss 监督最终密集掩码。
- 分类和掩码派生监督使用 focal loss。

### 2.5 推理与后处理

- 图像 resize 到 \(768 \times 768\)。
- 真伪判定：sigmoid 主 logit，阈值 0.5。
- 掩码后处理：二值化阈值 0.4，提取 8 连通域，丢弃面积小于 8 像素的组件，剩余组件转为原图坐标系下的 bounding box。
- bbox 坐标归一化到 0–1000 尺度，作为官方定位输出；真实图像返回空列表。

### 2.6 MLLM 解释生成

- 使用通用 MLLM **Qwen3.5-Flash**，不进行微调。
- 结构化上下文包括：
  - 原始图像；
  - 预测真伪概率；
  - 若预测为假：定位 overlay 图像 + 基于预测掩码裁剪的可疑区域局部图。
- 提示设计包含四类约束：
  1. 根据标签条件生成：假样本需给出局部取证证据；真样本描述视觉一致性。
  2. 基于结构化上下文，关注模型指示区域并与相邻正常区域比较。
  3. 写作风格为技术性取证标注，使用纹理不一致、光照不匹配、边缘伪影、解剖异常等稳定类别。
  4. 不暴露掩码、阈值、置信度、算法、坐标等内部实现细节。
