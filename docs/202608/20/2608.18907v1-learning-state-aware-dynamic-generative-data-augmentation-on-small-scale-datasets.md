## 摘要
小规模图像分类常受限于训练数据稀缺。基于预训练生成模型的生成式数据增强（GDA）已成为一种有效解决方案。然而，现有方法依赖任务无关的增强策略，忽视了下游模型的需求。尽管近年来的动态GDA方法引入模型反馈来指导增强，但它们仍难以可靠地确定样本特定的增强强度，并在平衡图像多样性和类别语义的同时使增强策略适应不同图像区域。为了解决这些问题，我们提出了学习状态感知的动态生成式数据增强（LSADA）。具体而言，LSADA根据每个样本当前损失和损失下降速率为其构建学习状态，然后将该状态映射为样本特定的增强强度。此外，LSADA引入了一种解耦的数据增强与扩散融合策略，对类别相关区域施加强度可控的变换，并生成多样化的类别无关区域，逐步融合它们以提高图像多样性，同时保持类别语义。在九个公开数据集上的实验表明，LSADA在六个自然图像数据集上平均比现有SOTA动态GDA方法高出4.5%，在三个医学图像数据集上高出2.5%。

## Abstract
Small-scale image classification is often limited by the scarcity of training data. Generative data augmentation (GDA) based on pretrained generative models has emerged as an effective solution. However, existing methods rely on task-agnostic augmentation strategies that overlook downstream model needs. Although recent dynamic GDA methods incorporate model feedback to guide augmentation, they still struggle to reliably determine sample-specific augmentation strengths and adapt augmentation strategies to different image regions while balancing image diversity and class semantics.   To address these issues, we propose learning-state-aware dynamic generative data augmentation (LSADA). Specifically, LSADA constructs a learning state for each sample based on its current loss and loss-decrease rate, which is then mapped to a sample-specific augmentation strength. Furthermore, LSADA introduces a decoupled data augmentation and diffusion fusion strategy that applies strength-controlled transformations to class-relevant regions and generates diverse class-irrelevant regions, progressively fusing them to improve image diversity while preserving class semantics. Experiments on nine public datasets show that LSADA outperforms the existing SOTA dynamic GDA method by an average of 4.5% on six natural image datasets and 2.5% on three medical image datasets.

- **现有方法不足**：
  - 静态 GDA 与下游模型训练过程无关，生成的图像可能无法针对模型弱点。
  - 动态 GDA 虽然引入下游模型反馈（如不确定性、分类结果）来选择样本，但存在两个关键挑战：
    - **挑战 1**：不同样本需要不同的增强强度。简单样本可能需要强增强增加难度，困难样本则只需轻微增强避免欠拟合；现有方法通常只能决定“是否增强”，无法给出样本特定的增强强度。
    - **挑战 2**：同一张图像内不同区域也需要不同增强强度。类别相关区域应轻度增强以保留语义，类别无关区域可强增强以提升多样性；现有方法往往对整幅图像统一处理。
- **论文目标**：提出 **LSADA（Learning-State-Aware Dynamic Generative Data Augmentation）**，一种学习状态感知的动态生成式数据增强方法，通过估计每个样本的学习状态来动态调整增强强度，并对类别相关/无关区域进行解耦增强与扩散融合，从而在小样本场景下同时提升图像多样性和类别语义保持能力。

## 2. 方法论

### 2.1 样本学习状态估计

- **核心思想**：利用每个样本的**当前损失**和**损失下降速率**来刻画其学习状态，而不是仅依赖预测结果。
- **公式定义**（文字说明）：
  - 当前损失：\(\ell_t^i = L(f_{\theta_t}(x_i), y_i)\)，表示模型在 epoch \(t\) 对样本 \(i\) 的分类损失。
  - 损失下降速率：\(\delta_t^i = (\ell_{t-k}^i - \ell_t^i) / (\ell_{t-k}^i + \epsilon_1)\)，衡量过去 \(k\) 个 epoch 内该样本被学习的进度。
  - 学习状态：\(\mathcal{L}_t^i = \ell_t^i - \beta \delta_t^i\)，其中 \(\beta > 0\) 平衡当前学习难度与近期学习进展。
- **含义**：较大的 \(\mathcal{L}_t^i\) 表示样本更难学（损失较高且改进缓慢），较小则表示该样本已较好掌握。

### 2.2 学习状态到增强强度的映射

- 首先对学习状态进行归一化：
  \[
  \tilde{\mathcal{L}}_t^i = \frac{\mathcal{L}_t^i - \min_j \mathcal{L}_t^j}{\max_j \mathcal{L}_t^j - \min_j \mathcal{L}_t^j + \epsilon_2}
  \]
- 然后映射到样本特定的增强强度：
  \[
  a_t^i = a_{\min} + (a_{\max} - a_{\min})(1 - \tilde{\mathcal{L}}_t^i)
  \]
- **原则**：学习状态大的样本（难样本）获得较弱增强，以保留语义特征；学习状态小的样本（易样本）获得较强增强，以增加多样性。

### 2.3 解耦数据增强与扩散融合生成

- **类别相关区域提取**：
  - 使用分割模型（如 SAM3）或类激活图（CAM）获取类别相关掩码 \(M_i\)。
  - 类别相关区域：\(x_i^r = M_i \odot x_i\)。
- **类别相关区域增强**：
  - 对 \(x_i^r\) 及其掩码 \(M_i\) 施加基于规则的变换（如旋转、Cutout、Resize），变换强度由 \(a_t^i\) 控制：
    \[
    \hat{x}_i^r = \mathcal{T}(x_i^r; a_t^i), \quad \hat{M}_i = \mathcal{T}(M_i; a_t^i)
    \]
- **类别无关区域生成**：
  - 使用大语言模型（LLM，如 GPT-5.5）根据类别标签生成多样化的背景提示（prompts），用于引导扩散模型生成背景。
- **扩散融合生成**：
  1. 将增强后的类别相关区域编码为潜变量：\(z_{i,0}^r = \text{Enc}(\hat{x}_i^r)\)。
  2. 对掩码进行最近邻下采样以匹配潜空间分辨率：\(\tilde{M}_i\)。
  3. 对 \(z_{i,0}^r\) 执行 **DDIM 反演**，得到融合区间 \([\tau_1, \tau_2]\) 内的反演轨迹。
  4. 从 \(\tau_2\) 开始，以背景提示为条件进行反向去噪；在每个去噪步骤中，将反演得到的类别相关潜变量注入掩码区域：
     \[
     z_{i,\tau-1} = \tilde{M}_i \odot z_{i,\tau-1}^r + (1 - \tilde{M}_i) \odot z_{i,\tau-1}
     \]
  5. 从 \(\tau_1\) 到 0 继续反向去噪（无掩码注入），最后解码得到生成图像 \(\hat{x}_{i,j}^t\)。
- **优势**：在潜空间中进行融合，避免直接粘贴导致的语义不一致或分布偏移，同时保留类别相关区域的结构并生成多样化背景。

### 2.4 训练流程

- 每 \(k\) 个 epoch 更新一次生成数据；在前 \(T=100\) 个 epoch 内进行生成，总生成比例 \(m=5\)。
- 生成样本与原始数据合并，用于后续分类器训练。

- LSADA 在九个数据集上均优于规则式增强和静态 GDA 方法，并显著超过现有动态 GDA SOTA ActGen：

- **问题针对性强**：准确识别了现有动态 GDA 的两个核心缺陷（样本级增强强度和区域级差异化增强），并提出针对性解决方案。
- **学习状态设计合理**：使用当前损失和损失下降速率，比仅依赖预测结果更能反映样本的学习难度和进展，且在小样本场景下更稳定。

- **可迁移性验证**：通过不同架构训练实验证明生成数据具有通用性，提升了方法实用价值。
