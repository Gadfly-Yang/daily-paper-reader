## 摘要
AI生成图像篡改定位旨在识别被编辑像素，但其OOD性能落后于图像级检测，部分原因在于像素级监督将取证证据与数据集特定的掩码几何和语义边界纠缠在一起。将图像级分布对齐扩展到定位任务，我们构建了COCO-ControlNet，利用源图像的Canny边缘和深度图对齐语义与几何，从而提升多个定位器的OOD性能。然而，更严格的掩码VAE重建对齐（Mask-VAE）表现不如COCO-ControlNet，表明VAE重建伪影难以迁移到局部扩散修复伪影。我们还发现了“边界粘附”现象：微调后的分割模型会将预测结果贴合到语义对象轮廓上，而非真实的篡改边界。这些发现启发了GAP-SAM，该方法将图像及其冻结的VAE重建编码为一个全局伪影token，并通过零门控FiLM在像素解码前注入SAM3的特征金字塔。该token不预先指定空间区域，而是调节密集解码，以保持定位能力，同时抑制语义边界捷径。在六个数据集上，GAP-SAM平均达到79.8 Pixel-F1，比最强现有方法高出12.6个百分点。此外，在JPEG压缩、高斯模糊和缩放的所有测试严重程度下，它均表现最佳。

## Abstract
AI-generated image manipulation localization identifies edited pixels, but its OOD performance lags behind image-level detection partly because pixel supervision entangles forensic evidence with dataset-specific mask geometry and semantic boundaries. Extending image-level distribution alignment to localization, we construct COCO-ControlNet with source-image Canny edges and depth maps to align semantics and geometry, improving OOD performance across multiple localizers. Yet tighter Mask-VAE Reconstruction Alignment (Mask-VAE) underperforms COCO-ControlNet, showing that VAE reconstruction artifacts transfer poorly to local diffusion-inpainting artifacts. We also identify \emph{boundary adhesion}, where fine-tuned segmentation models snap predictions to semantic object contours rather than true manipulation boundaries. These findings motivate GAP-SAM, which encodes an image and its frozen VAE reconstruction into a global artifact token and injects it into SAM3's feature pyramid via zero-gated FiLM before pixel decoding. Without prescribing a spatial region, this token modulates dense decoding to preserve localization while suppressing semantic-boundary shortcuts. Across six datasets, GAP-SAM averages 79.8 Pixel-F1, outperforming the strongest prior method by 12.6 points. It also performs best at every tested severity of JPEG compression, Gaussian blur, and resizing.

## 1. 论文的核心问题与整体含义

- **核心问题**：AI生成图像篡改定位（Image Manipulation Localization, IML）在分布外（OOD）场景下泛化能力明显弱于图像级检测，但现有研究对其成因和缓解方式仍不充分。
- **问题根源分析**：
  - 像素级监督要求模型将取证证据精确关联到像素位置，而篡改掩码本身包含数据集的形状、位置、面积、语义边界等非因果捷径，模型容易依赖这些数据集特定模式。
  - 与图像级分类相比，定位任务在共享主干的多任务设置下跨域F1下降更大，说明定位对分布偏移更敏感。
  - 微调自预训练分割模型时，会出现**边界粘附（boundary adhesion）**：模型预测会贴合语义对象轮廓，而非真实篡改边界，因为预训练学到的语义边界与篡改边界并不一致。
- **整体含义**：需要一种既能利用分割模型强空间表征，又能抑制语义边界捷径、增强取证证据迁移性的定位方法；同时，需要重新审视“更严格分布对齐是否一定带来更好 OOD 性能”。

## 2. 论文提出的方法论

论文提出 **GAP-SAM**，核心思想是将输入图像与其冻结 VAE 重建编码为**全局伪影先验 token**，在不预设空间区域的前提下，用该 token 调节 SAM3 的密集解码，抑制语义边界捷径、保持定位能力。

### 2.1 全局伪影先验（Global Artifact Prior）

- 输入图像 \(x\) 分别经过：
  - **自适应 SAM3 图像编码器** \(\Phi_\theta(x)\)，得到 L 层 FPN 特征金字塔 \(F^o = \{F_l^o\}_{l=1}^L\)，用于定位。
  - **冻结 SAM3 编码器** \(\Phi'(R(x))\)，对 VAE 重建 \(R(x)\) 提取特征，得到重建特征金字塔 \(F^r = \{F_l^r\}_{l=1}^L\)。
- 取两个分支的最终层 256 维特征 \(F_L^o\) 和 \(F_L^r\)：
  - 分别做全局平均池化（GAP）和分支特定 LayerNorm，得到两个 256 维描述符 \(h^o\) 和 \(h^r\)。
  - 将 \([h^o; h^r]\) 拼接后，经过两层线性变换 + GELU + LayerNorm，得到 256 维的**全局伪影先验 token** \(t_{art}\)。
- 关键点：对最终特征做 GAP **去除了空间坐标**，因此 \(t_{art}\) 不包含空间掩码提案，只表征重建相关伪影证据。

### 2.2 FPN 掩码解码中的零门控 FiLM 注入

- 使用**零门控 FiLM** 将 \(t_{art}\) 注入到观测图像的多尺度 FPN 特征 \(F^o\) 中，在每个 FPN 级别上做通道级调制：
  \[
  \tilde{F}_l^o = F_l^o \odot (1 + \alpha_f \gamma_f) + \alpha_f \beta_f
  \]
- 其中 \([\gamma_f; \beta_f]\) 由 \(t_{art}\) 通过线性投影得到；共享标量门 \(\alpha_f\) **初始化为 0**，使训练初期调制为恒等变换。
- 注入位置在 SAM3 的**像素解码器之前**，使先验同时影响 DETR 解码器的查询特征和像素解码器的密集嵌入，但不修改 SAM3 原生掩码解码结构。
- 由于 FiLM 调制在空间上广播，它提供全局取证上下文，而不引入具体的重建区域或边界。

### 2.3 学习目标

- 定位损失采用 SAM3 官方微调配置，记为 \(L_{SAM3}\)。
- 额外引入 **artifact classifier**：将 \(h^o\) 和 \(h^r\) 分别送入共享分类器，令真实原图标签为 0、VAE 重建为 1，使用 BCE 损失：
  \[
  L_{art} = \frac{1}{2|B_{real}|} \sum_{i \in B_{real}} [\text{BCE}(\ell_{o,i},0) + \text{BCE}(\ell_{r,i},1)]
  \]
- 总损失：\(L = L_{SAM3} + \lambda_{art} L_{art}\)（论文取 \(\lambda_{art}=1.0\)）。
- Artifact classifier 只作用于全局池化描述符，**不引入掩码、边界或其他空间监督**，用于锚定潜在特征到真实 vs 重建的生成轴，使 token 成为更明确的取证先验。

## 6. 论文的主要结论与发现

- 定位任务比图像级检测对 OOD 偏移更敏感；像素监督会与掩码几何、语义边界等非因果因素纠缠。
- COCO-ControlNet 通过 Canny/深度条件对齐语义和几何，能一致提升多个现有定位器的 OOD 性能。
- **Mask-VAE 并非更优**：更严格的像素对齐（VAE 重建替代掩码区域）反而削弱 OOD 泛化，说明 VAE 重建伪影在空间支持和伪影形成机制上与局部扩散修复伪影存在双重不匹配。
- 直接微调分割模型会出现**边界粘附**，即预测贴合语义对象轮廓而偏离真实篡改边界。
- GAP-SAM 将冻结 VAE 重建的全局伪影先验注入 SAM3 特征金字塔，通过零门控 FiLM 和图像级伪影分类引导，可有效抑制语义捷径。
