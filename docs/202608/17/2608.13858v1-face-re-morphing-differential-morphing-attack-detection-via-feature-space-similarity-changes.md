## 摘要
人脸变形攻击对人脸识别系统构成严重威胁，因为单张变形证件图像可与多个贡献者匹配。差分变形攻击检测（D-MAD）通过将证件图像与受信任的活体图像进行比较来应对这一威胁，但现有方法通常依赖静态特征差异、组成人脸重建或多线索融合。本文提出 Face Re-morphing，一种 D-MAD 方法，利用特征空间对额外变形操作的响应作为检测线索。给定一张证件图像和一张受信任的活体图像，所提方法生成一张重新变形图像，并利用证件-活体与活体-重新变形之间余弦相似度的变化作为检测分数。在 FRLL-Morphs 和 FEI Morph 上的实验表明，所提线索在不同变形条件、重新变形方法和人脸识别模型下均有效。与现有方法的比较在 AMSL 上显示出有利结果，并表明所提方法在 FEI Morph Version 1 的 Criminal 条件下表现良好，尤其是在使用 MorDIFF 时。这些结果表明，重新变形引起的相似度变化为 D-MAD 提供了一种互补线索。

## Abstract
Face morphing attacks pose a serious threat to face recognition systems because a single morphed document image can be matched to multiple contributors. Differential morphing attack detection (D-MAD) addresses this threat by comparing a document image with a trusted live image, but existing methods often rely on static feature differences, constituent-face reconstruction, or multi-cue fusion. This paper proposes Face Re-morphing, a D-MAD method that uses the feature-space response to an additional morphing operation as a detection cue. Given a document image and a trusted live image, the proposed method generates a re-morphed image and uses the change between the document--live and live--re-morphed cosine similarities as the detection score. Experiments on FRLL-Morphs and FEI Morph show that the proposed cue is effective across different morphing conditions, re-morphing methods, and face recognition models. Comparisons with existing methods show favorable results on AMSL and indicate that the proposed method performs well under the Criminal condition on FEI Morph Version~1, particularly when using MorDIFF. These results indicate that re-morphing-induced similarity change provides a complementary cue for D-MAD.

- **研究背景**：人脸变形攻击（face morphing attack）对人脸识别系统构成严重威胁。攻击者将两个不同个体的面部图像融合生成一张变形证件照，若该照片被合法证件采用，则可被多个贡献者共同使用，破坏“一人一证”的身份对应关系，威胁边境控制等场景。
- **研究问题**：现有差分变形攻击检测（D-MAD）方法主要依赖静态特征差异、组成人脸重建或多线索融合，在跨变形条件、跨特征提取器时稳定性不足，且往往未将“变形操作”本身作为检测信号。
- **核心含义**：本文提出一种新的 D-MAD 思路——**Face Re-morphing**，即对文档图像与受信任活体图像再执行一次变形操作，观察特征空间中相似度的变化，利用“重变形引起的相似度变化”作为检测线索。其本质是将原本用于攻击的变形技术转化为检测工具，从动态响应的角度而非静态差异的角度区分真实图像与变形图像。

## 2. 论文提出的方法论

### 2.1 核心思想

- 假设真实（bona-fide）文档图像与活体图像属于同一身份，其嵌入向量接近；此时对两者做重变形，得到的重变形图像仍应处于同一身份簇内，因此文档-活体相似度与活体-重变形相似度差异很小（Δs ≈ 0）。
- 假设文档图像是变形图像（由 A 和 C 两人组成），活体图像为其中一人（如 C）。变形文档图像的嵌入位于两者之间，与活体 C 的相似度低于正常类内相似度；经过与活体 C 的重变形后，重变形图像会更靠近 C 的嵌入分布，使得活体-重变形相似度升高，因此 Δs 通常为正。
- 通过计算 Δs 并将其作为检测分数，可以区分真实对与变形攻击对。

### 2.2 关键技术细节

- **输入**：文档图像 D，受信任活体图像 L。
- **重变形图像生成**：对 D 和 L 进行人脸对齐后，采用某种变形方法生成重变形图像 Re。本文比较了三种重变形方法：
  - **MorDIFF**：基于扩散自编码器，在表示空间中插值潜在表示生成变形图像。
  - **OpenCV**：基于 68 点 dlib 特征点的 Delaunay 三角剖分 + 仿射变换 + 线性混合，图像级经典变形。
  - **StyleGAN2-ADA**：将输入投影到 W 空间，线性插值后通过生成器合成图像。
- **特征提取**：将 D、L、Re 分别输入同一人脸特征提取器 F，得到特征向量 \(F_D\)、\(F_L\)、\(F_{Re}\)。
- **分数计算**：
  \[
  s_{\text{base}} = \cos(F_D, F_L), \quad s_{\text{re}} = \cos(F_L, F_{Re})
  \]
  \[
  \Delta s = s_{\text{re}} - s_{\text{base}}
  \]
  Δs 即为最终检测分数，表示重变形过程引入的相似度变化量。

### 2.3 算法流程（文字描述）

1. 文档图像 D 与活体图像 L 进行人脸对齐；
2. 以 α = 0.5 的等权重混合系数，使用选定变形方法生成重变形图像 Re；
3. 分别提取三张图像的人脸特征；
4. 计算 D 与 L 的余弦相似度 \(s_{\text{base}}\)，以及 L 与 Re 的余弦相似度 \(s_{\text{re}}\)；
5. 用 \(Δs = s_{\text{re}} - s_{\text{base}}\) 作为检测分数，分数越高越可能为变形攻击。

## 6. 论文的主要结论与发现

- **方法有效性**：重变形引起的相似度变化（Δs）在多个数据集、多种变形条件、多种重变形方法和多个特征提取器上均能提供有效的 D-MAD 判别信号。
- **性能表现**：
  - 在 FRLL-Morphs 上，OCV 和 MD 表现优异（EER 可低至 0.001 或更低），SG2-A 表现较差。
  - 在 FEI Morph Version 2 上，MD 和 OCV 依然较好，SG2-A 最差；Criminal 条件普遍优于 Accomplice 条件。
  - 与现有方法比较，在 AMSL 上 OCV 达到零错误（EER=0.000，B0.01=0.000），MD 也有竞争力；在 FEI Morph Version 1 的 Criminal 条件下，MD 和 OCV 的 EER 达到 0.010，优于所有对比方法。
- **分数消融结论**：Δs 明显优于仅使用 \(s_{\text{re}}\)；但相对于 \(s_{\text{base}}\) 的改进依赖于重变形方法——OCV 和 MD 改善明显，SG2-A 反而变差。
- **分布规律**：真实样本的 Δs 分布集中在 0 附近，变形样本的 Δs 明显向正方向偏移，支持理论假设。
- **核心结论**：重变形诱导的相似度变化是一种有效且互补的 D-MAD 线索，可增强现有检测体系。

## 7. 优点

- **思路新颖**：首次将“主动重变形”引入 D-MAD，利用特征空间的动态响应而非静态差异，为变形攻击检测提供了新范式。
- **方法简单、训练无关**：无需训练检测模型，仅依赖余弦相似度差异，便于部署和解释。
- **理论支撑清晰**：给出了 bona-fide 和 morphing 情况下的几何直觉和数学论证，逻辑自洽。
- **实验设计规范**：使用公开配对协议、标准评估指标、多种特征提取器和多种重变形方法，增强了结果的可信度。
- **跨模型稳定性好**：在四个不同结构的人脸识别模型上，主要结论一致，说明方法不强烈依赖特定特征空间。
- **在关键基准上表现突出**：AMSL 上 OCV 零错误，FEI-M1 的 Criminal 条件下明显优于现有方法，显示实际应用潜力。

## 8. 不足与局限

- **对重变形方法高度敏感**：StyleGAN2-ADA 表现远差于 OpenCV 和 MorDIFF，方法效果受所选变形技术影响大；文中虽定性归因于身份漂移，但缺少定量分析。
