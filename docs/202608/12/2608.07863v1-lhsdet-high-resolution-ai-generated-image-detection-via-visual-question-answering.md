## 摘要
在扩散模型与自回归模型进展的推动下，AI生成图像的保真度和分辨率如今已可与真实图像相媲美。然而，现有AI生成图像检测方法通常会下采样图像，不可避免地忽略了高分辨率AI生成图像中关键的底层纹理细节，从而限制了检测性能。此外，未知生成模型不断涌现，使得大规模预训练数据集难以获取。为应对这些挑战，我们提出了一种新型高分辨率AI生成图像检测器，称为LHSDet。具体而言，我们将AI生成图像检测任务形式化为视觉问答问题，利用微调后的视觉-语言框架充分挖掘视觉与文本模态之间的互补信息。鉴于现有视觉-语言模型的默认视觉编码器并非为AI生成图像检测量身定制，我们重新设计了视觉编码器，以更好地捕获AI生成图像中固有的底层与高层伪影。此外，我们引入了语义级文本分支，实现多模态特征融合与检测。因此，LHSDet采用三分支架构提取互补的多模态特征：底层视觉分支聚合非重叠图像块以获取局部纹理线索，基于SigLIP2的高层视觉分支用于全局感知特征提取，以及语义级文本分支利用BLIP-2生成图像描述。大量实验结果表明，LHSDet在多种生成模型（包括扩散模型和自回归模型）上均取得了较高的检测精度和鲁棒性能。

## Abstract
Driven by advances in diffusion models and autoregressive models, the fidelity and resolution of AI-generated images now rival those of real images. However, existing AI-generated image detection methods often downsample the images, inevitably overlooking critical low-level texture details in high-resolution AI-generated images, therefore limiting their detection performance. In addition, the ceaseless emergence of unknown generative models makes large-scale pre-training datasets inaccessible. To address these challenges, we propose a novel high-resolution AI-generated image detector, termed LHSDet. Specifically, we formulate the AI-generated image detection task as a Visual Question Answering problem, leveraging a fine-tuned vision-language framework to fully exploit the complementary information between visual and textual modalities. Recognizing that the default visual encoder of existing vision-language models is not tailored for AI-generated image detection, we redesign a visual encoder to better capture both the low-level and high-level artifacts inherent in AI-generated images. Furthermore, we incorporate a semantic-level textual branch to enable multi-modal feature fusion and detection. Consequently, LHSDet employs a triple-branch architecture to extract complementary multi-modal features: a low-level visual branch that aggregates non-overlapping patches for local texture cues, a high-level visual branch based on SigLIP2 for global perception feature extraction, and a semantic-level textual branch that generates captions using BLIP-2. Extensive experimental results demonstrate that LHSDet achieves high detection accuracy and robust performance across diverse generative models, including both diffusion and autoregressive models.

## 2. 论文提出的方法论

### 2.1 核心思想

- 将 AI 生成图像检测转化为 VQA 任务：输入图像与问题，输出“是/否”判断。
- 采用**三分支架构**提取互补特征：
  - **低级视觉分支**：捕捉局部纹理、噪声模式、相邻像素关系。
  - **高级视觉分支**：基于 SigLIP2 提取全局感知特征、语义不一致等高层线索。
  - **语义级文本分支**：使用 BLIP-2 生成图像描述（caption），作为文本模态信息。
- 使用 **LoRA** 对 SigLIP2、BLIP-2、Phi-3-mini 进行参数高效微调，适应少样本检测任务。

### 2.2 关键技术细节

#### 2.2.1 视觉编码模块（Visual Encoding Module, VEM）

- **局部纹理块（Local Texture Block）**：
  - 将输入图像划分为**非重叠图像块（non-overlapping patches）**，保留纹理细节并破坏全局语义。
  - 使用 **SRM（Spatial Rich Model）** 高通滤波器提取噪声模式特征 \(F_{noise}\)，保持冻结以避免过拟合。
  - 通过卷积提取相邻像素关系特征 \(F_{pixel}\)：
    \[
    F_1 = [X_p; \text{Conv}_1(X_p)], \quad F_{pixel} = \text{Conv}_2([F_1; \text{Conv}_2(F_1)])
    \]
  - 将 \(F_{noise}\) 与 \(F_{pixel}\) 通过卷积融合（而非通道拼接），得到低级局部特征 \(F_{local}\)。

- **全局感知块（Global Perception Block）**：
  - 使用 **SigLIP2** 视觉编码器处理 384×384 分辨率的输入（默认处理 1024×1024 图像），提取高层视觉特征 \(F_{global}\)。
  - 通过 LoRA 微调编码器，使其更适合 AI 生成图像检测。

- **交叉注意力融合（Cross-Attention Fusion）**：
  - 将高层特征 \(F_{global}\) 作为 Query，低级特征 \(F_{local}\) 作为 Key 和 Value，进行交叉注意力计算。
  - 融合输出与原始全局特征残差连接并经过 LayerNorm，得到最终视觉特征 \(V_{visual}\)。
  - 这种设计实现“全局引导的局部注意力”，同时保留高层语义与低层细节。

#### 2.2.2 文本编码模块（Textual Encoding Module, TEM）

- 使用 **BLIP-2** 以提示“A detailed description of this image”生成输入图像的描述 \(T_{desc}\)。
- 将描述与原始问题拼接，形成完整问题：
  > “Based on the image description: ‘\(T_{desc}\)’, assess the authenticity. Is this image real?”
- 该文本作为语义级特征，增强多模态推理能力。

#### 2.2.3 多模态特征融合模块（Multi-Modal Feature Fusion Module, MFM）

- 将视觉特征 \(V_{visual}\) 通过线性投影映射到 LLM 的隐藏空间：
  \[
  V_{proj} = W_{visual-proj} V_{visual} + b_{visual-proj}
  \]
- 文本问题经 tokenization 和 embedding 得到 \(E_{text}\)。
- 将视觉 token 与文本 token 沿序列维度拼接：
  \[
  E_{multi-modal} = [V_{proj}; E_{text}]
  \]
- 视觉信息作为前缀 token，使 LLM 能同时关注视觉和文本信息。

#### 2.2.4 LLM 推理模块（LLM Reasoning Module, LRM）

- 采用 **Phi-3-mini**（3.8B 参数）作为 LLM 推理引擎，平衡性能与效率。
- 多模态序列输入 LLM，通过自注意力机制实现跨模态推理。
- 取最后 token 的隐藏状态 \(h_{final}\) 进行二分类预测，输出“Yes”（真实）或“No”（AI 生成）。

#### 2.2.5 训练策略

- 使用 **LoRA** 微调 SigLIP2、BLIP-2、Phi-3-mini，设定 rank \(r=8\)，\(\alpha=16\)，dropout \(d=0.05\)，目标层为 q_proj 和 v_proj。
- 仅优化低秩矩阵 \(A_{lora}, B_{lora}\)，更新公式：
  \[
  W_{LoRA\_proj} = W_{proj} + A_{lora} B_{lora}
  \]
- 损失函数为**二元交叉熵（BCE）**：
  \[
  \mathcal{L}_{BCE} = -\frac{1}{N}\sum_{i=1}^{N} [y_i \log p_i + (1-y_i)\log(1-p_i)]
  \]
- 优化器为 Adam，学习率 \(1\times10^{-5}\)，权重衰减 0.001，batch size 1，训练 2 个 epoch。

## 6. 论文的主要结论与贡献

- **主要结论**：
  - LHSDet 通过将检测任务转化为 VQA 问题，结合低级纹理、高级语义和文本描述三种互补特征，在少样本训练条件下显著提升了高分辨率 AI 生成图像的检测性能。
  - 在 Flickr2K + 11 个生成数据集的泛化测试中，LHSDet 取得了最高的平均准确率，且对未见过的扩散模型、自回归模型和社交媒体图像均表现出强鲁棒性。
  - 在 DIV2K 少样本场景下，LHSDet 仍保持领先，证明其对训练数据量的需求较低。
  - 消融实验表明，低级视觉分支、高级视觉分支和文本分支均对性能有重要贡献，交叉注意力融合优于简单拼接，LoRA 微调在保持性能的同时大幅降低了可训练参数量。

- **核心贡献**：
  1. **提出高分辨率检测范式**：突破传统下采样至 256×256 的做法，直接在 1024×1024 分辨率上处理，保留纹理细节和噪声模式，更适合检测高分辨率生成图像。
  2. **多模态 VQA 框架**：首次将视觉问答引入高分辨率 AI 生成图像检测，利用图像描述作为语义级提示，增强模型推理能力。
  3. **轻量化参数高效微调**：采用 LoRA 微调三个大型预训练模型（SigLIP2、BLIP-2、Phi-3-mini），可训练参数仅占 0.23%，实现高效训练与部署。
  4. **全面的泛化与鲁棒性验证**：在多个未见生成模型（含自回归模型）和真实社交媒体图像上进行了广泛测试，并考虑了多种后处理攻击，证明了方法的实用价值。
