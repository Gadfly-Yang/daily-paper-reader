## 摘要
AI生成图像检测器在训练和测试图像来自不同生成器或数据集时泛化能力较差。尽管DINO等视觉基础模型产生了丰富的空间表示，现有检测器通常仅使用全局聚合的CLS token对图像进行分类。我们假设将DINO特征全局聚合到单个CLS token中会掩盖空间分布的生成痕迹。为验证这一假设，我们提出了PatchHead，一个轻量级的空间聚合头，它保留DINO patch token的二维组织结构，并整合相邻区域的证据。在训练过程中，我们冻结预训练的DINO骨干网络，仅优化插入的LoRA适配器、PatchHead和辅助投影头。在涵盖人工整理和真实场景的九个跨数据集基准上，PatchHead在七个数据集上排名第一，在其余两个数据集上排名第二。它将最强先前方法的平均平衡准确率从91.6%提高到94.6%（+3.0个百分点），并将最差情况准确率从82.4%提高到89.4%（+6.9个百分点），同时仅增加8.6%的可训练参数和0.08%的额外FLOPs。进一步的定性分析表明，PatchHead (i) 减少了类别条件域差异，并且 (ii) 将表示从内容主导的显著性转向空间分布的真实性证据。总之，这些观察从表示层面解释了为什么空间patch聚合比基于单个CLS的全局表示能更可靠地跨生成器和数据集迁移。我们的代码和模型将在接收后公开。

## Abstract
AI-generated image detectors generalize poorly when their training and test images originate from different generators or datasets. Despite the rich spatial representations produced by vision foundation models like DINO, existing detectors typically classify images using only the globally aggregated CLS token. We hypothesize that globally aggregating DINO features into a single CLS token obscures spatially distributed generation traces. To test this hypothesis, we introduce PatchHead, a lightweight spatial aggregation head that preserves the two-dimensional organization of DINO patch tokens and integrates evidence across neighboring regions. During training, we freeze the pretrained DINO backbone and optimize only the inserted LoRA adapters, PatchHead, and auxiliary projection head. Across nine cross-dataset benchmarks spanning manually curated and in-the-wild settings, PatchHead ranks first on seven datasets and second on the remaining two. It improves the strongest prior method from 91.6% to 94.6% in average balanced accuracy (+3.0 points) and raises the worst-case accuracy from 82.4% to 89.4% (+6.9 points), while introducing only 8.6% more trainable parameters and 0.08% additional FLOPs. Further qualitative analysis suggests that PatchHead (i) reduces class-conditional domain discrepancy, and (ii) redirects the representation from content-dominated saliency toward spatially distributed authenticity evidence. Together, these observations provide a representation-level account of why spatial patch aggregation transfers more reliably across generators and datasets than a single CLS-based global representation. Our code and models will be made available upon acceptance.

## 1. 论文的核心问题与整体含义

- **研究背景**：AI生成图像检测（AIGID）本质上是一个分布外（out-of-distribution）识别问题。检测器在训练生成器与测试生成器不同、或训练数据集与测试数据集分布不同时，性能会大幅下降。
- **核心问题**：现有基于视觉基础模型（如DINO）的检测器通常只使用全局聚合的 **CLS token** 进行分类，完全忽略了 patch token 的空间组织。然而，生成痕迹往往是**弱、局部且分散在多个区域**的，不一定位于语义最显著的对象上。
- **研究假设**：将 DINO 特征全局压缩到单个 CLS token 会**削弱空间分布的生成证据**，同时保留图像内容和数据集特有变化，从而限制跨域泛化能力。
- **整体含义**：论文试图隔离一个单一设计选择——“DINO 表示是应该被全局压缩成 CLS token，还是应该在图像级聚合之前进行空间建模？”。其目标不是设计新的骨干网络或复杂取证架构，而是检验是否保留和聚合空间 patch 证据能带来更可靠的跨生成器/数据集迁移。

## 2. 论文提出的方法论

- **骨干与训练方式**：
  - 使用 **DINOv3 ViT-L/16** 作为视觉编码器。
  - **冻结原始 DINO 权重**，只优化插入的 **LoRA 适配器**（rank=8，作用于 QKV 投影、注意力输出投影和两个 MLP 线性层）。
  - 训练过程中只更新 LoRA 适配器、PatchHead 和辅助投影头。

- **PatchHead 核心结构**：
  1. **Reshape**：将 patch token 序列恢复为原始二维空间布局 \( F_0 \in \mathbb{R}^{D \times H_p \times W_p} \)。
  2. **深度卷积（DWConv 3×3）**：对空间相邻 patch 之间进行信息交互，建模局部空间关系。
  3. **GELU 激活 + 1×1 点卷积**：混合特征通道，并将 DINO 维度投影到检测头维度。
  4. **全局平均池化（GAP）**：得到图像级 patch 表示 \( f_{\text{patch}} \)。
  5. **线性分类器**：输出真实性概率 \( \hat{y} = \sigma(w^\top f_{\text{patch}} + b) \)。

- **训练目标**：
  - 主损失：图像级二分类交叉熵损失 \( L_{\text{cls}} \)。
  - 辅助损失：在 **CLS token** 上施加对比学习损失 \( L_{\text{con}} \)，用于正则化 LoRA 适配后的骨干网络。
  - 总损失：\( L = (1-\lambda)L_{\text{cls}} + \lambda L_{\text{con}} \)，其中 \(\lambda=0.5\)（由消融确定）。
  - **CLS 分支仅在训练时使用，推理时丢弃**，最终预测完全依赖空间 patch 表示。

- **关键设计对比**：
  - 简单全局平均 patch token（GAP+Linear）并不会自动改善泛化，反而略低于 CLS 基线。
  - 打乱 patch 空间位置后性能下降，说明原生二维邻接关系有帮助。
  - 3 层 MLP 头也不如 PatchHead，说明改进不能仅归因于额外容量。

## 7. 优点

- **方法简洁高效**：仅用 3×3 深度卷积 + 1×1 点卷积 + 全局平均池化，参数量和 FLOPs 增加极小（+8.6% 参数、+0.08% FLOPs），易于部署。
- **单一设计选择隔离**：通过严格对比 CLSHead、GAP+Linear、PatchHead+Shuffle 等，清晰证明了空间建模的价值，排除了容量和 patch 访问本身的影响。
- **实验全面**：覆盖 9 个基准、细粒度生成器/来源、多种消融、鲁棒性测试和可视化分析，证据链完整。
- **表示级解释**：不仅报告性能，还通过 t-SNE、空间响应统计等分析揭示了为什么空间 patch 聚合能提升泛化，提供了可解释的机制洞察。
- **训练成本低**：冻结骨干 + LoRA，只训练一个 epoch，适合快速实验和实际应用。
- **代码将公开**：有利于复现和后续研究。

## 8. 不足与局限

- **单骨干验证**：仅使用 DINOv3 ViT-L/16，未验证其他视觉基础模型（如 DINOv2、CLIP、其他 ViT 规模）或 CNN 骨干，泛化结论可能受限于该特定模型。
- **单一训练数据**：训练仅使用 DDA-aligned COCO-SD-2 数据集，可能无法覆盖所有生成范式，与某些对手动数据集的强基线相比存在潜在的训练分布偏差。
- **训练轮次少**：只训练 1 个 epoch，虽然与基线协议一致，但可能未达到最佳收敛，且对学习率、数据增强等超参数较敏感。
- **缺乏统计稳定性评估**：未报告多次运行的均值和方差，也未进行统计显著性检验，难以评估结果波动。
- **鲁棒性测试有限**：仅测试 JPEG60、Resize2.0、Blur2.0 三种扰动，未涉及更多实际后处理（如截图、社交媒体压缩、噪声、颜色变化等）。
- **真实场景数据集规模不均衡**：SynthWildX（1,739 张）和 BFree-Online（813 张）较小，结果可能受样本量影响。
- **对比方法一致性**：部分基线结果来自原论文或修正值（表中用 * 标记），虽然注明，但仍可能存在不完全对等的训练/评估条件。
- **应用限制**：方法聚焦于 DINO 空间特征的重组，未探索与显式取证线索（如频率、重构残差）的融合；在极端模糊等场景下仍有挑战。
