## 摘要
面部生物特征识别系统当前面临生成式人工智能与高保真物理欺骗相互交织的复合威胁。现有防御存在系统性瓶颈，包括泛化能力差、推理过程不可审计，以及依赖大规模低质量数据集。为应对这些挑战，我们提出了用于人脸防伪检测的多模态大语言模型（MFAD），这是一个面向统一人脸防伪检测（UFAD）的可解释推理系统，并配套一个语义级标注基准。与依赖外部工具或粗粒度对齐的方法不同，MFAD通过细粒度的像素-语义锚定机制激活多模态大语言模型（MLLMs）的内在推理能力。这消除了定位幻觉，并确保推理路径可审计。我们引入了一种跨攻击类型的语义级统一标注范式：仅对每类攻击标注1000个精确掩码，即可生成严格对应于欺骗区域的推理证据链。在Qwen-VL基础模型上进行监督微调表明，使用有限的高质量样本，系统在域内ACER上实现了40-50%的相对降低，并将跨域性能退化限制在11.62%/5.23%以内，显著优于现有框架。此外，在白盒对抗攻击下，检测准确率仅下降3.2%，验证了与基于大规模短文本数据训练的模型相比，语义锚定的鲁棒性。领域从业者对推理路径的证据可靠性评分为4.57/5，推理延迟满足实时部署要求。这些结果证实，少样本、高质量的语义标注范式对于构建可信、可解释且成本高效的统一人脸防伪检测系统是有效的。

## Abstract
Facial biometric recognition systems currently face compound threats intertwining generative AI and high-fidelity physical spoofing. Existing defenses suffer from systemic bottlenecks, including poor generalization, non-auditable reasoning, and reliance on massive, low-quality datasets. To address these challenges, we propose Multimodal Large Language Models (MFAD) for face anti-spoofing detection, an explainable reasoning system for Unified Face Anti-Spoofing Detection (UFAD), accompanied by a semantic-level annotation benchmark. Unlike methods relying on external tools or coarse alignment, MFAD activates the intrinsic reasoning capabilities of Multimodal Large Language Models (MLLMs) via a fine-grained pixel-semantic anchoring mechanism. This eliminates localization hallucinations and ensures auditable reasoning paths. We introduce a cross-attack semantic-level unified annotation paradigm: by annotating only 1,000 precise masks per attack category, we generate reasoning evidence chains strictly corresponding to spoofed regions. Supervised fine-tuning on the Qwen-VL foundation model demonstrates that, using limited high-quality samples, the system achieves a 40-50% relative reduction in in-domain ACER and restricts cross-domain performance degradation to within 11.62%/5.23%, significantly outperforming existing frameworks. Furthermore, under white-box adversarial attacks, detection accuracy drops by only 3.2%, validating the robustness of semantic anchoring compared to models trained on massive short-text data. Domain practitioners rated the evidence reliability of reasoning paths at 4.57/5, with inference latency satisfying real-time deployment requirements. These results confirm that a few-shot, high-quality semantic annotation paradigm is effective for building trustworthy, explainable, and cost-efficient UFAD systems.

## 2. 论文提出的方法论

### 2.1 核心思想

- 利用 **细粒度像素-语义锚定机制** 激活 MLLM 的内在推理能力，将视觉伪造线索显式绑定到推理链中。  
- 通过 **跨攻击类型语义级统一标注范式**，仅每类攻击标注约 1000 个精确掩码，生成严格对应欺骗区域的推理证据链。  
- 采用监督微调（SFT）+ LoRA 参数高效适配，在 Qwen-VL 基础模型上实现统一物理与数字攻击检测。

### 2.2 关键技术细节

#### （1）语义级联合掩码生成

- 定义颜色编码的语义标注协议：  
  - 攻击类型分为 **C_deepfake（数字伪造）**、**C_display（显示重放）**、**C_mask（物理面具）**。  
  - 对每类攻击细分语义区域，如数字伪造包含额头、眉毛、眼睛、耳朵、鼻子、面颊、嘴、下巴、胡须、脖子、衣物、背景等 12 类；显示攻击包含轮廓、光照、文字、摩尔纹、扭曲、图标等；面具攻击包含面部面具、区域面具、3D 面具、上半身面具等。  
- 使用双射映射 Φ: C → Z³ 为每个语义类别分配唯一 RGB 像素值，生成多类伪造定位的监督信号。  
- 掩码在像素位置 (x, y) 的生成规则如式：  
  - M_i(x,y) = Φ(c) 若 (x,y) ∈ Ω_c，否则为背景 (0,0,0)。

#### （2）CoT 证据生成与数据管线

- 基于掩码图像与原图，利用大语言模型（如 Gemini）驱动生成原始推理响应 R_raw = F_gen(I, M, P_sys, K_aux)。  
- 设计 **三阶段 CoT 模板**：观察（Observation）→ 归因（Attribution）→ 判断（Judgment），每个证据链必须显式锚定像素级掩码。  
- 构建复合提示空间 P_total = {P_cat, P_sub, P_trace, P_role, P_cot}，涵盖类别选择、细粒度子类型、23 种伪造痕迹、系统角色与 CoT 要求。  
- 采用**双模型共识自适应过滤机制**：  
  - GPT-4o 与 Qwen 分别打分 S_GPT、S_Qwen；  
  - 若两者均高于质量阈值 τ=3 且差异小于一致性阈值 δ=1，则接受；若差异大但某者高于 τ，则进入人工复审；否则拒绝。  
- 人工细化阶段执行错误归因诊断（事实错误、逻辑错误、知识错误），并进行特征对齐、逻辑插值、知识注入。  
- 最终构建约 16,000 个经过三级验证的语义锚定 CoT 训练样本。

#### （3）训练目标与优化

- 采用标准自回归交叉熵损失进行 SFT：  
  - L(θ) = -∑_{t=1}^T log P(y_t | y_<t, x; θ)  
- 将后训练形式化为 KL 信任域约束下的优化问题，防止奖励攻击。  
- 使用 **LoRA 低秩适配**：  
  - 冻结预训练权重，注入可训练低秩分解矩阵；rank r=8，缩放因子 α=32。  
  - 前向计算：h = W₀x + BAx。  
  - 从内在维度和数据-参数效率两个角度论证低秩配置足以捕捉逻辑对齐，避免过拟合与灾难性遗忘。

## 6. 主要结论与发现

- **域内性能**：  
  - MFAD-7B 在 CelebA-Spoof 上 ACER 为 0.0357，BPCER 为 0；在 MS-UFAD-Deepfake 上 ACER 为 0.0101。  
  - 相较基模型和通用大模型，仅在少量高质量 CoT 样本上微调即可达到或优于大规模短文本数据的效果。  
- **跨域泛化**：  
  - CoT 模型在 MFFI 上 AUC 约 0.67，显著高于短文本微调模型（约 0.51–0.59），体现了推理机制在分布偏移下的稳定性。  
  - 但 MFAD-7B 在 MFFI 上的 ACER 仍高达 0.359，表明极端 OOD 性能有限。  
- **对抗鲁棒性**：  
  - 白盒攻击下，CoT 模型在物理域精度仅下降 1.41%，数字域下降约 7.12%，远低于短文本模型的 10.55% 和 20.62%。  
  - CoT 的长链推理起到“语义低通滤波”作用，滤除高频对抗噪声。  
- **可解释性与质量**：  
  - 人类专家对推理链证据可靠性评分为 4.7619，GPT-4.1 为 4.7046，Qwen-3.6 为 4.2536。  
  - 领域从业者平均评分 4.57/5。  
- **强化学习探索**：  
  - GRPO 在 SFT 后进一步训练并未提升 OOD 泛化，反而导致 ID 性能崩溃和灾难性遗忘，说明当前 RL 配置不适合此任务。
