## 摘要
不可见图像水印越来越多地用于深度伪造检测和溯源跟踪，它们不仅要能承受偶然的失真，还要能抵抗故意的移除。我们在现代神经后处理水印架构中重新审视了扩频嵌入这一经典水印原理。我们的出发点是一个测量：在现有的编码器-解码器方案中，每个消息比特只占据图像的一小部分，这是导致其脆弱性的一个共同因素，因为移除时只需干扰该比特占据的区域。相比之下，SpreadMark将每个比特作为密集的伪随机码字扩散到整个图像，并通过匹配滤波一个学习到的抑制载体芯片表示来恢复它，并采用并行卷积解码路径和稀疏化感知训练。条件芯片空间分析表明，在与码字无关的扰动模型下，密集扩展增加了破坏匹配滤波器恢复所需的预算。在COCO和DIV2K上对九种方案进行评估，SpreadMark是唯一一种在我们测试的重生成和潜在空间稀疏化设置下仍保持高检测率的方法，同时在JPEG压缩和加性噪声鲁棒性上具有竞争力。它使嵌入水印不可察觉，在COCO和DIV2K上保持了高感知质量。

## Abstract
Invisible image watermarks are increasingly used for deepfake detection and provenance tracking, where they must survive not only incidental distortions but also deliberate removal. We revisit spread-spectrum embedding, a classical watermarking principle, inside a modern neural post-hoc watermarking architecture. Our starting point is a measurement: in existing encoder-decoder schemes each message bit occupies only a small fraction of the image, a shared contributing factor to their fragility, since removal then need only disturb the region a bit occupies. SpreadMark instead spreads each bit as a dense pseudo-random codeword over the whole image and recovers it by matched-filtering a learned cover-suppressed chip representation, with a parallel convolutional decoding path and sparsification-aware training. A conditional chip-space analysis shows that, under a codeword-independent perturbation model, dense spreading increases the budget required to disrupt matched-filter recovery. Evaluated on COCO and DIV2K against nine schemes, SpreadMark is the only evaluated method retaining high detection under both the regeneration and the latent-space sparsification settings we test, with competitive JPEG and additive-noise robustness. It keeps the embedded watermark imperceptible, maintaining high perceptual quality on both COCO and DIV2K.

### 2. 论文提出的方法论
#### 核心思想
- 将经典扩频通信原理引入神经后处理水印架构：每个消息比特被分配一个固定的伪随机码字（覆盖整张图像），编码时叠加多个码字的加权和，解码时通过匹配滤波恢复比特。

#### 关键技术细节
- **编码器**：  
  - 残差结构：水印图像 `x_w = Π( x + g_θ(x,b) + α·s(b) )`，其中 `g_θ` 为学习到的CNN残差，`s(b)` 为扩频信号，`Π` 为像素值截断。  
  - 扩频信号：`s(b) = (1/√K) Σ (2b_i - 1) c_i`，`c_i` 为独立高斯伪随机码字（均值为0、逐像素方差为1），`α` 为可学习的幅度缩放因子。
- **解码器**：  
  - 使用全卷积骨干提取特征，经1×1卷积投影获得载波抑制“芯片”图 `ˆz`。  
  - **匹配滤波路径**：计算每个比特的相关系数 `ρ_i = ⟨ˆz, c_i⟩/d`，作为恢复统计量。  
  - **卷积路径**：通过全局平均池化和线性层输出比特logits，作为并行解码器。  
  - **融合**：通过可学习的门限 `γ_i` 和仿射变换结合两条路径，最终比特概率为 `σ( h_i + γ_i (a_i ρ_i + β_i) )`。
- **稀疏化感知对抗训练 (SA‑AT)**：  
  - 模拟潜在空间稀疏化攻击，将图像特征投影到低秩子空间，通过多步梯度优化实现。  
  - 训练时以一定概率替换原始水印图像，强制解码器适应低秩扰动。
- **损失函数**：结合鲁棒性比特损失、干净比特损失、辅助卷积头损失以及视觉质量损失（L2 + LPIPS）。

### 3. 实验设计

- **基准方法 (9种)**：HiDDeN、MBRS、StegaStamp、SepMark（重新训练类）；CIN、TrustMark、RivaGAN、WAM、DwtDctSvd（使用已发布模型）。重新训练类采用统一128×128分辨率、30比特载荷，其他按原始配置。
- **攻击类型**（四大类）：  
  - 标准失真：JPEG、高斯噪声、高斯模糊、80％中心裁剪后缩放。

### 5. 实验数量与充分性
- **主要对比实验**：在 COCO 和 DIV2K 两个数据集上，展示了10种方法的20项鲁棒性指标（BA和DA）与3项视觉质量指标（总计不少于200个测量点）。
- **消融实验**：围绕嵌入增益、图像分辨率、有效载荷比特数、解码路径（完整、纯匹配滤波、纯卷积头）四个维度进行，每个维度多个取值点，并度量四种攻击下的表现。
- **额外实验**：分析了白盒攻击强度变化曲线、失真和重生成强度变化曲线，验证了SA-AT的贡献，对比了码字设计（高斯 vs 伯努利，固定 vs 可学习幅度）。

### 6. 论文的主要结论与发现
- **扩散嵌入带来独特的鲁棒性**：SpreadMark是唯一在重生成攻击和潜在空间稀疏化攻击下均保持高检测率（DA接近或等于1.00）的方法。
- **标准失真下竞争性**：在JPEG压缩和高斯噪声下保持高比特准确率和检测率，但在模糊和裁剪等空间同步破坏的攻击上表现较弱（固定码字易失同步）。
- **对抗白盒移除是弱项**：在30 dB PSNR设置下，检测率降为0，但适当提高嵌入能量（至24 dB）即可恢复强鲁棒性，说明该弱点由嵌入能量决定而非解码器设计。
- **视觉质量**：SpreadMark达到30.1 dB PSNR，优于重新训练的基线（约24 dB），但远低于一些高视觉质量方案（如TrustMark的~41 dB和WAM的~49 dB），因此在鲁棒性与不可见性间取得了折中。
- **理论支撑**：条件芯片空间分析给出了扩频有助于抵御与码字独立的扰动的解释，且消融实验证实匹配滤波路径是中坚力量。

### 7. 优点
- **创新性强**：将经典扩频原理与可学习元素（载波抑制芯片、门控融合、SA‑AT）有机结合，并给出了理论分析。
- **问题导向明确**：通过测量每比特足迹揭示了现有方法的共性弱点，并以此设计解决方案。
- **实验全面**：覆盖四大类攻击，与9种方法基准对比，包含细致消融和不同攻击强度的分析，并强调了质量与鲁棒性的权衡。
- **可解释性好**：匹配滤波器和卷积路径的贡献明确，SA‑AT的效果通过对照实验得以分离。

### 8. 不足与局限
- **码本安全性未经验证**：使用单一固定伪随机码本，且假设密钥不泄露；论文明确指出未评估已知消息攻击、码字估计、碰撞攻击等，这在实际部署中是重大安全隐患。
- **高分辨率下重生成性能下降**：随着图像分辨率增大（从128→256），重生成鲁棒性急剧恶化，表明目前的密集编码设计不适合大尺寸图像。
- **模糊和裁剪攻击下鲁棒性弱**：空间同步失配会导致固定码字相关失效，该问题未被解决。
- **高不可见性与对抗鲁棒性存在矛盾**：为获得高对抗移除鲁棒性，需要降低视觉质量（如降至24 dB），限制了该方案在苛刻不可感知要求场景下的应用。
- **理论假设严格**：芯片空间保证依赖攻击扰动与码字统计独立，真实场景中攻击者可利用水印图像本身间接获取码字相关性，定理仅解释了理想化条件，非实际安全保障。
