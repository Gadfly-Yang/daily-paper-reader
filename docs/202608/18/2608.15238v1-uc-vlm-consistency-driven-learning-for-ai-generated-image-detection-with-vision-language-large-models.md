## 摘要
视觉-语言大模型（VLLMs）在AI生成图像（AIGI）检测中具有前景，因为它们既能给出预测，也能产生自然语言输出。然而，现有基于VLLM的检测器主要微调语言侧，而对低级视觉取证线索关注有限。它们还通常依赖人工设计的提示或人工标注的推理依据，这限制了可扩展性。我们提出UC-VLM，一个仅依赖二值监督的统一多阶段AIGI检测框架。UC-VLM首先自动识别有效的指令变体。随后在多阶段训练框架中复用同一二值标签：（i）视觉判别目标，增强对非语义取证线索的敏感性；（ii）标签条件生成目标，利用二值标签监督文本输出。这一设计将弱二值监督转化为视觉通路和语言输出共享的监督信号。我们的关键创新是一个统一的多阶段二值监督框架，它一致地复用相同的真实性标签用于视觉适配和标签条件文本生成，同时利用自动优化的指令降低提示敏感性，无需人工撰写的推理依据或手工设计的提示。实验表明，UC-VLM在GenImage上达到96.1%的平均准确率，比此前最强结果高出4.6%；在Chameleon上，ProGAN/SDV1.4训练设置下分别取得69.6%/77.9%的准确率，分别超过最佳基线11.2%/15.3%。

## Abstract
Vision-Language Large Models (VLLMs) are promising for AI-generated image (AIGI) detection because they can produce both a prediction and a natural-language output. However, most existing VLLM-based detectors primarily fine-tune the language side while giving limited attention to low-level visual forensic cues. They also often depend on manually crafted prompts or human-annotated rationales, which limits scalability.We present UC-VLM, a unified multi-stage framework for AIGI detection that relies solely on binary supervision. UC-VLM first identifies effective instruction variants automatically. It then reuses the same binary label within a multi-stage training framework: (i) a visual discrimination objective that strengthens sensitivity to non-semantic forensic cues, and (ii) a label-conditioned generation objective that uses the binary label to supervise textual outputs. This design turns weak binary supervision into a shared supervision signal for both the visual pathway and the language output. Our key novelty is a unified multi-stage binary-supervised framework that consistently reuses the same authenticity labels for visual adaptation and label-conditioned text generation, while leveraging automatically optimized instructions to reduce prompt sensitivity without requiring human-written rationales or hand-crafted prompts.Experiments show that UC-VLM achieves 96.1% average accuracy on GenImage, exceeding the strongest prior result by 4.6%, and obtains 69.6% / 77.9% accuracy on Chameleon under ProGAN / SDV1.4 training, surpassing the best baseline by 11.2% / 15.3%, respectively.

## 2. 论文提出的方法论

### 2.1 总体框架

- UC-VLM 基于 **Qwen2.5-VL-7B**，训练时只有图像级真实/生成二值标签。
- 总体损失为：  
  \( L = L_{\text{vis}} + L_{\text{text}} \)，  
  其中 \(L_{\text{vis}}\) 用于视觉通路适配，\(L_{\text{text}}\) 用于标签条件文本生成。
- 三个核心组件：
  1. **Visual Adaptation（视觉适配）**
  2. **Instruction Optimization（指令优化）**
  3. **Label-Conditioned Regeneration（标签条件再生成）**

### 2.2 Visual Adaptation（视觉适配）

- 目的：增强视觉编码器对**局部非语义取证线索**的敏感性，减少对高层语义的依赖。
- 技术细节：
  - 对输入图像进行**随机局部裁剪**，裁剪尺寸满足：  
    \( h' \sim U(\frac{1}{8}H, \frac{1}{4}H), \quad w' \sim U(\frac{1}{8}W, \frac{1}{4}W) \)
  - 将裁剪后的图像划分为 \(N\) 个 patch，并**随机打乱 patch 的空间顺序**：
    \( \tilde{I}' = \text{Reassemble}(\{p_{\pi(i)}\}_{i=1}^N), \quad \pi \sim P(N) \)
  - 该操作保留局部纹理统计，同时破坏全局空间一致性，促使模型关注纹理、结构异常等取证线索。
  - 打乱后的图像编码为视觉 token，与文本 token 融合，通过 BCE 损失优化二分类：
    \( L_{\text{vis}} = -[y\log(\hat{y}) + (1-y)\log(1-\hat{y})] \)

### 2.3 Instruction Optimization（指令优化）

- 目的：自动寻找**有效且较稳定**的指令表述，减少对人工提示的依赖。
- 方法：
  - 以结构化基础模板 `BASE_PROMPT` 作为起点，使用 LLM 生成 \(N\) 个候选指令，初始化指令池。
  - 在验证子集上评估每个候选指令的检测准确率，保留 **Top-k** 高性能指令。
  - 将性能最好的指令记为 `Prompt-B`，作为后续默认查询。
  - 从保留指令中随机选择父指令，交给 LLM 进行：
    - **语义改写**（保留含义、改变措辞），或
    - **推理表达修改**（改变指令结构），各以 0.5 概率执行。
  - 生成子指令后，与 Top-k 父指令合并为新指令池，保持池大小 \(N\)。
  - 迭代 \(M\) 轮，逐步探索多样且语义相关的指令变体。
- 算法流程见原文 Algorithm 1。

### 2.4 Label-Conditioned Regeneration（标签条件再生成）

- 目的：将**同一二值标签**扩展到语言侧监督，训练文本输出，而无需人工理由。
- 方法：
  - 使用最优指令 \(p_{\text{best}}\)，VLM 对图像 \(x_j\) 生成文本和预测：
    \( (r_j, \hat{y}_j) = f_{\text{VLM}}(x_j, p_{\text{best}}) \)
  - 若预测正确（\(\hat{y}_j = y_j\)），保留生成文本 \(r_j\)；
  - 若预测错误，则在前面加入**标签指令** \(d_j\)，强制指定真实标签后重新生成，得到 \(r'_j\)。
  - 构建再生成数据集：
    \( D_{\text{regen}} = \{(x_j, r_j, y_j) \mid \hat{y}_j = y_j\} \cup \{(x_j, r'_j, y_j) \mid \hat{y}_j \neq y_j\} \)
  - 冻结视觉编码器，仅用自回归目标微调语言模块：
    \( L_{\text{text}} = -\sum_{(x,r,y)\in D_{\text{regen}}} \log p_\theta(r \mid x, y, p_{\text{best}}) \)
- 注意：生成文本仅作为辅助训练信号，**不保证忠实于图像证据**，可能产生幻觉；论文不声称其是可验证的解释。

## 6. 论文的主要结论与发现

- **统一二值监督有效**：UC-VLM 仅利用真实/生成二值标签，即可同时优化视觉取证敏感性和语言侧文本输出。
- **性能显著提升**：在 GenImage 平均准确率 96.1%，超越此前最强 4.6%；在 Chameleon 上超越最佳基线 11.2%/15.3%。
- **组件互补**：视觉适配、指令优化、标签条件再生成三者结合能取得最佳效果，单独使用任一组件效果有限。
- **指令敏感性问题可缓解**：自动指令优化能发现更有效的指令表述，减少对人工提示的依赖。
- **可扩展监督**：标签条件再生成使二值标签能够监督文本输出，无需人工推理依据。
- **文本输出定位**：生成文本不作为可验证解释，仅作为辅助训练信号，用于稳定预测。

## 7. 优点

- **监督信号利用高效**：仅需二值标签，不依赖人工理由、操纵掩码或细粒度取证标注，显著降低数据成本。
- **统一框架设计**：将视觉适配、提示优化、语言生成纳入同一二值监督目标，避免各模块独立优化带来的不一致。
- **关注低层取证线索**：通过随机裁剪和 patch shuffle，引导视觉编码器关注局部纹理、结构异常，而非高层语义。
- **自动指令优化**：降低对人工提示工程的依赖，并提高对提示变化的稳定性。
- **实验性能提升明显**：在两个挑战性基准上均取得大幅提升，尤其跨域场景（Chameleon）提升幅度显著。
