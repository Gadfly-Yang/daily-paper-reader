## 摘要
人工智能的日益普及导致AI生成视频迅速增多，这使得区分真实内容和被篡改内容变得更加困难。现有许多检测方法依赖单一模型，往往难以泛化到不同类型的深度伪造。本研究开发了一种多模态深度伪造检测系统，它通过模型集成结合音频和视觉分析。该系统包括用于音频检测的AASIST，以及用于分析视频帧视觉特征的EfficientNet、XceptionNet和MesoNet。流程以视频为输入，分离音频，并使用MTCNN提取面帧。每个模型产生一个分数，指示输入为伪造的可能性。然后使用包括均值平均和堆叠在内的集成策略组合这些分数。均值融合提供了一个简单且稳定的基线，而堆叠则使用训练好的元模型来学习如何更有效地组合预测。结果表明，虽然单个模型在其训练数据集上表现良好，但在更多样化的数据集上测试时性能下降。集成方法通过组合多个模型的预测，有助于提高整体鲁棒性，从而在不同类型的深度伪造上实现更一致的性能。这表明，同时使用音频和视觉信息是一种更可靠的深度伪造检测方法。我们的结果凸显了对未见过的篡改手法的泛化能力是核心开放挑战，平均准确率约为70%。

## Abstract
The increasing accessibility of artificial intelligence has led to a rapid rise in AI-generated videos, making it more difficult to distinguish between real and manipulated content. Many existing detection methods rely on a single model and often struggle to generalize across different types of deepfakes. In this work, we developed a multimodal deepfake detection system that combines both audio and visual analysis using an ensemble of models. The system includes AASIST for audio-based detection, and EfficientNet, XceptionNet, and MesoNet for analyzing visual features in video frames. The pipeline takes a video as input, separates the audio, and extracts face frames using MTCNN. Each model produces a score indicating the likelihood of the input being fake. These scores are then combined using ensemble strategies, including mean averaging and stacking. Mean fusion provides a simple and stable baseline, while stacking uses a trained meta-model to learn how to combine predictions more effectively. Results show that while individual models perform well on the datasets they were trained on, their performance drops when tested on more diverse datasets. The ensemble approach helps improve overall robustness by combining predictions from multiple models, leading to more consistent performance across different types of deepfakes. This suggests that using both audio and visual information together is a more reliable approach for deepfake detection. Our results highlight generalization to unseen manipulations as the central open challenge, with average accuracy around 70%.

## 二、论文提出的方法论

### 2.1 总体流程
- 系统以视频为输入，首先执行通用预处理：
  - **音视频分离**：将视频拆分为音频流和视觉帧流。
  - **人脸检测与提取**：利用 OpenCV 提取固定采样率的帧，再通过 MTCNN 检测并裁剪出人脸区域。
- 经过预处理后，数据被送入四个独立模型的专属流水线，得到各自的伪造概率分数。
- 最后，通过多种集成策略将各模型分数融合为一最终预测，并依据阈值 0.5 决定最终“真实/伪造”标签。

### 2.2 个体模型及其预处理
- **音频模型 AASIST**（Audio Anti-Spoofing using Integrated Spectro-Temporal Graph Attention Networks）：
  - 直接处理原始音频波形（16 kHz 单声道），经卷积层提取低层级时频特征，再通过谱-时图注意力层建模长距离依赖，输出两类 logits（真实/欺骗），经 softmax 得到欺骗概率。
  - 预处理包括格式转换、重采样、填充或截断至固定长度。
- **视觉模型 EfficientNet‑B1**：
  - 人脸帧经 ImageNet 标准化（减均值、除标准差），缩放至 240×240，使用 Albumentations 增强，最后通过 EfficientNet‑B1 提取特征并二分类输出。
- **视觉模型 XceptionNet**：
  - 人脸帧转换为 RGB，缩放至 299×299，归一化（均值/标准差为 0.5），送入基于深度可分离卷积的 Xception 网络，最终全连接层被替换为二分类头。
- **视觉模型 MesoNet (Meso4)**：
  - 为兼容历史实现，MesoNet 在独立 Python 虚拟环境中以 Keras 服务形式运行，通过 HTTP 通信。
  - 人脸帧被转为 NumPy 数组，归一化至 0‑1，缩放至 256×256，送入 4 层卷积+2 层全连接的 Meso4 架构。

### 2.3 集成融合策略
- **均值融合 (Mean Fusion)**：对有效模型分数直接取平均，忽略缺失值。简单、稳定，作为基线。
- **堆叠 (Stacking)**：
  - 先利用基模型在验证集上的预测分数训练一个元模型（meta-model）。
  - 元模型以固定顺序的特征（AASIST、EfficientNet、MesoNet、XceptionNet 分数）为输入，学习如何加权组合。
  - 若某模型缺失，则以 0.5（最大不确定性）填充，保证流水线不中断；若堆叠模型文件不可用，则自动回退至均值融合。
- **其他策略**（用于对比）：
  - 多数投票 (Majority Voting)：各模型先转化为硬标签，按票数决定。
  - 加权平均 (Weighted Average)：对不同模型赋予不同固定权重后平均。
  - 加权投票 (Weighted Voting)：硬标签加权投票。

## 六、主要结论与发现

- **单模型泛化差**：各模型在训练域上表现良好（AASIST 在 ASVspoof LA 上 eval EER 0.94%，准确率 99.16%；EfficientNet 在 FaceForensics++ 上达 72%），但在跨域的 FakeAVCeleb 上性能大幅下降（例如 XceptionNet 仅 60.40%，AASIST 几乎随机）。
- **集成提升稳健性**：通过组合模型可以有效平滑单模型误差，在包含各类伪造的平衡测试集上，投票类集成方法可取得约 71–73% 的准确率，优于任一单模型。
- **视觉模型占主导**：当视频存在视觉伪造痕迹时，视觉模型能有效驱动集成，提升准确率；当仅有音频伪造（视频为真）时，集成准确率大幅降至 51.4%，表明音频模型几乎未提供有效信息，集成严重依赖视觉分支。
- **硬标签融合优于软分数平均**：加权投票和多数投票的性能优于均值融合或加权平均，暗示将模型输出转化为二值决策，可减少置信度波动带来的噪声，提高稳定性。
- **核心挑战**：整体准确率仅约 70%，揭示从已知训练分布向未见过的生成方式泛化仍十分困难，模型容易学到数据集特定的伪影而非通用伪造特征。

## 七、优点

- **多模态与多模型集成**：系统性地结合音频和视觉两大模态，选取多种架构的模型，利用特征多样性提升检测鲁棒性。
- **融合策略对比全面**：考察了从简单平均到学习式堆叠等多种集成方法，论证了硬投票方法在噪声抑制上的优势。
- **现实流水线设计**：考虑实际部署中的失败案例，设置了缺失值时用 0.5 填充、堆叠失败时回退至均值融合等容错机制，增强了系统的实用性。
- **清晰的泛化性分析**：通过 FakeAVCeleb 中不同伪造组合的拆分实验，明确揭示了音频模型的域差距和系统对视觉模态的依赖，为后续研究指明了方向。

## 八、不足与局限

- **数据集偏差与不平衡**：FakeAVCeleb 原始数据严重偏向假样本，尽管在测试时做了重采样，但训练阶段仍可能受到类别不平衡的影响。同时，各模型在不同数据集上分开训练，训练分布不一致。
- **缺少与先进方法的直接对比**：未将提出的集成系统与近几年其他多模态深伪检测方案（如基于 Transformer 的融合、时序模型等）进行横向比较，无法评估其在领域中的竞争力。
- **音频模型贡献极弱**：AASIST 在真实场景音频上泛化失败，基本退化为真实分类器，使音频模态未能发挥应有作用，整体多模态优势未能充分体现。
- **未进行系统消融实验**：未逐一移除各基础模型来定量分析每个组件对集成性能的贡献；也未对比不同视觉模型组合的效果。
- **计算资源信息缺失**：不提 GPU 型号、训练时长等，难以评估方法的实际部署成本和可复现性。
- **时序信息利用不足**：视觉模型均以帧级方式处理，未捕捉时序闪烁、帧间不一致等视频层面上重要的深度伪造痕迹。
