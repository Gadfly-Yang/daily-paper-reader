## 摘要
人脸识别系统的应用日益广泛，随之而来的是日益多样化的安全威胁。现有数据集缺乏对伪造线索的详细文本描述，导致大多数先前方法主要将人脸攻击检测视为视觉识别任务。本文基于包含超过800万张攻击图像的大规模MS-UFAD数据集，为每张图像补充了伪造线索的细粒度文本描述。此外，我们提出了双对齐伪造网络（DAF-Net）以更好地利用这些文本信息。大量实验表明，我们的方法从攻击图像中提取了更具泛化性和语义意义的伪造表征，其性能优于仅使用视觉信息的方法以及基于粗粒度描述的方法。

## Abstract
The growing applications of facial recognition systems are accompanied by increasingly diverse security threats. Existing datasets lack detailed textual descriptions of forgery cues, leading most prior methods to treat face attack detection primarily as a visual recognition task. In this paper, building upon the large-scale MS-UFAD dataset which contains over 8 million attack images, we enrich each image with a fine-grained textual description of forgery cues. Furthermore, we propose a Dual Alignment Forgery Network(DAF-Net) to better leverage these textual information. Extensive experiments demonstrate that our approach extracts more generalizable and semantically meaningful forgery representations from attack images, outperforming both vision-only methods and approaches based on coarse-grained descriptions.

### 2. 论文提出的方法论

*   **核心思想**：通过细粒度的文本描述来引导模型关注图像中真正的伪造区域，并学习图像区域与文字短语之间的对齐关系，从而提取鲁棒的伪造特征。
*   **关键技术细节：细粒度文本描述生成**
    *   **流程**：使用预训练人脸攻击检测模型 + ScoreCAM算法定位图像中的被篡改区域；对比攻击图像与对应真实人脸在颜色、模糊度上的量化差异；开发针对不同伪造类型（如换脸）的“伪造痕迹语料库”；最后，将上述量化差异和语料库线索构建成Prompt，输入多模态大语言模型InternVL3，生成针对每张图像独一无二的、详细的伪造痕迹描述。
    *   **成果**：为MS-UFAD数据集中的800多万张图像生成了细粒度文本标注。
*   **模型架构：双对齐伪造网络(Dual Alignment Forgery Network, DAF-Net)**
    *   **双分支结构**：包含一个视觉分支和一个文本分支，分别使用BLIP模型的视觉编码器和文本编码器提取特征。推理时，仅使用视觉分支。
    *   **语义伪造聚合模块(Semantic Forgery Aggregation Module, SFAM)**：视觉和文本分支各有一个SFAM。每个SFAM由堆叠的Transformer层（含交叉注意力机制）构成，并使用N个可学习的查询向量，将离散的视觉补丁/文本令牌聚合成N个语义完整的视觉区域/文本短语，解决了跨模态对齐时的粒度不匹配问题。
    *   **跨模态对齐损失函数**
        *   **全局对齐损失($L_{global}$)**：采用对比损失，最大化同一图像-文本对的全局特征（$v$, $z$）的余弦相似度，最小化不同对的相似度。
        *   **细粒度对齐损失($L_{fine}$)**：采用基于后期交互的令牌级最大相似度匹配和三元组损失。对视觉区域特征$V$和文本短语特征$Z$计算令牌级相似度矩阵，对每一行和列取最大值并求平均，得到细粒度对齐分数$H(I_i,T_j)$。然后使用三元组损失，拉近正样本对$(I_i,T_i)$，推远难负样本对。
        *   **总损失函数**：$L = L_{cls} + \lambda(L_{global} + L_{fine})$，其中$L_{cls}$是两个分支各自的分类损失。
