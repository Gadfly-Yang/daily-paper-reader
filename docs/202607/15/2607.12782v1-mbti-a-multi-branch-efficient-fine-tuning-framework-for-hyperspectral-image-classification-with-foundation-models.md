## 摘要
高光谱基础模型能够从大规模无标签数据中学习可迁移的光谱-空间表征，为仅有少量标签样本的下游高光谱图像分类任务提供了一种有效的适应范式。然而，不同传感器间的光谱波段配置差异显著，导致模型直接迁移困难。现有适应策略通常对原始光谱进行压缩、选择或重塑以匹配模型特定的输入需求，这些操作可能丢弃有用的光谱信息并削弱局部光谱连续性。为解决这一问题，我们提出了MBTI，一种用于高光谱图像分类的多分支高效微调框架。MBTI在保留全波段光谱信息的同时，使基础模型适应下游分类任务。首先，我们引入一种保留光谱连续性的多分支预处理策略：将原始高光谱图像划分为多个连续光谱子集，当剩余波段无法构成完整分支时采用波段重用机制，从而避免无效填充和不必要的光谱信息损失。其次，在每个分支中插入独立的低秩适应（LoRA）模块，使不同光谱区间学习特定于任务的判别特征，同时冻结大部分预训练参数。最后，通过多分支通道注意力融合模块自适应地重新校准并整合所有光谱分支的特征。在三个公开高光谱数据集上的实验结果表明，MBTI与代表性分类方法相比具有竞争力和优越性。在秩-8配置下，仅约2.33%至2.36%的参数参与训练。代码将发布于https://github.com/Azhenmiddleblock/MBTI/tree/main。

## Abstract
Hyperspectral foundation models learn transferable spectral-spatial representations from large-scale unlabeled data. They provide an effective paradigm for adapting to downstream hyperspectral image (HSI) classification tasks with limited labeled samples. However, spectral band configurations vary substantially across sensors, which makes direct model transfer difficult. Existing adaptation strategies often compress, select, or reshape the original spectra to match model-specific input requirements. These operations may discard useful spectral information and weaken local spectral continuity. To address this problem, we propose MBTI, a Multi-Branch efficient fine-tuning framework for Hyperspectral Image classification. MBTI adapts hyperspectral foundation models to downstream classification tasks while preserving full-band spectral information. First, we introduce a spectral-continuity-preserving multi-branch preprocessing strategy. The original HSI is divided into multiple continuous spectral subsets, and a band reuse mechanism is used when the remaining bands cannot form a complete branch. This avoids invalid padding and unnecessary spectral loss. Second, independent Low-Rank Adaptation (LoRA) modules are inserted into each branch. They enable different spectral intervals to learn task-specific discriminative features while keeping most pre-trained parameters frozen. Finally, a multi-branch channel attention fusion module adaptively recalibrates and integrates features from all spectral branches. Experiments on three public hyperspectral datasets show that MBTI achieves competitive and superior performance compared with representative classification methods. Under the final rank-8 configuration, only about 2.33\%--2.36\% of the parameters are trainable. The code will be available at https://github.com/Azhenmiddleblock/MBTI/tree/main.

## 方法论
### 核心思想
将全波段HSI划分为多个连续光谱组（分支），通过波段复用避免零填充，每个分支独立使用冻结的预训练编码器并插入低秩适应（LoRA）模块，最后用通道注意力融合多分支特征。

### 关键技术细节
- **光谱连续性保持的多分支预处理**
  - 设输入HSI为 $X \in \mathbb{R}^{H \times W \times B}$，每分支所需波段数为 $M$。分支数 $N = \lceil B/M \rceil$。
  - 前 $N-1$ 个分支取连续波段：$X_i = X_{:,:,(i-1)M+1:iM}$。
  - 若最后分支波段剩余 $R = B-(N-1)M < M$，复用前一组末尾的 $D = M-R$ 个波段，形成连续输入：$X_N = \text{Concat}_\lambda (X_{:,:,(N-1)M-D+1:(N-1)M}, X_{:,:,(N-1)M+1:B})$。从而保留光谱连续，避免无效填充。

- **光谱多分支LoRA微调**
  - 每个分支的预训练编码器 $E_i^{\text{LoRA}}$ 保持冻结，仅插入分支独立的低秩矩阵 $A_i, B_i$。
  - 前向计算：$h_i = W_0 U_i + \frac{\alpha}{r} B_i A_i U_i$，其中 $W_0$ 冻结，$A_i \in \mathbb{R}^{r \times d_{in}}$，$B_i \in \mathbb{R}^{d_{out} \times r}$。
  - LoRA 被注入到 Transformer 块中的查询、键、值、输出投影以及前馈网络的两个线性变换中，形成分支特定的适配。

- **多分支光谱-通道重标定融合**
  - 分支特征 $Z_i = P_i(E_i^{\text{LoRA}}(X_i))$，其中 $P_i$ 为可训练的投影层，将多级编码器特征压缩为 $L \times C$ 的表示。
  - 拼接：$Z = \text{Concat}_c (Z_1, \dots, Z_N) \in \mathbb{R}^{L \times NC}$。
  - 全局通道描述子 $s_c = \frac{1}{L} \sum_{l=1}^L Z_{l,c}$，经两层瓶颈门控 $g = \sigma(W_2 \delta(W_1 s))$ 生成权重。
  - 重标定：$\tilde{Z}_{l,c} = g_c Z_{l,c}$。
  - 通过多层感知机头 $H = \phi_3(\phi_2(\phi_1(\tilde{Z} W_1' + b_1') W_2' + b_2') W_3 + b_3)$ 和线性分类器输出 logits。

### 算法流程
```
对每个分支：
  提取分支特征 Fi = E_i^LoRA(Xi)
  投影 Zi = Pi(Fi)
拼接 Z = Concat_c(Z1,...,ZN)
计算全局描述子 s，生成门控 g
重标定特征 tilde_Z
过渡头 H = MLP(tilde_Z)
分类 logits O = H W_cls + b_cls
```

## 主要结论与发现
- MBTI 在所有三个数据集上取得最优 OA 和 Kappa，显著优于现有方法。
- 光谱连续性保持的分支预处理比 PCA 降维更有效（PCA替换使性能明显下降），证明保留原始光谱结构的重要性。
- 分支特定的 LoRA 模块不可或缺；去除后 OA 下降（尤其在 SA 和 TF 上）。
- 通道注意力融合优于直接拼接和通用注意力机制，有效抑制冗余、增强判别特征。
- 仅约 2.33%–2.36% 的参数可训练，大幅降低训练状态内存（98.53 MiB vs. 全微调的 2963.85 MiB），实现参数高效微调。
- 跨框架（Jittor）推理验证了部署灵活性，Jittor 下峰值显存进一步下降（3484→2502 MiB），精度基本保持。

## 优点
- **光谱无损设计**：多分支连续光谱划分+波段复用，巧妙避开传统输入适配的信息丢失问题。
- **高效微调**：冻结主干、分支独立 LoRA，参数和内存效率极高，适合小样本场景。
- **自适应融合**：基于通道注意力重标定分支特征，充分利用光谱区间间差异。
- **实验丰富且规范**：三数据集、多类型对比方法、消融和超参数分析全面，且有跨框架验证。
- **可复现性**：公开代码，详细描述实现细节。
