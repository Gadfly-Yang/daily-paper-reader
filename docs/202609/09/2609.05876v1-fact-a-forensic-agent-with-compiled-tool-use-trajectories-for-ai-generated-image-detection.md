## 摘要
AI生成图像检测正日益成为开放世界问题：新的图像生成器产生高度逼真的图像，使得视觉伪影更难被识别。现有检测器通常依赖一组固定的取证线索，因此对某一生成器家族有效的检测器可能对另一个失效。我们提出FACT（具有编译工具使用轨迹的取证智能体），它学习一种以图像为条件的工具使用策略来进行取证分析。FACT并非应用固定检测器，而是决定调用哪些取证工具，解释返回的证据，并在收集到足够证据时停止。FACT遵循“演化—蒸馏—精炼”流程：它演化一种经执行验证的取证技能，将该技能编译为“动作—观察”工具使用轨迹，将其蒸馏为紧凑的智能体，并用成本感知的GRPO精炼策略。在两个内部基准和四个公开基准上，FACT在所有比较方法中取得了最佳性能，包括在近期未见过的生成器、深度伪造和篡改图像上。

## Abstract
AI-generated image detection is increasingly open-world: new image generators produce highly realistic images that make visual artifacts harder to identify. Existing detectors usually rely on a fixed set of forensic cues, so a detector that works well for one generator family may fail on another. We introduce FACT (Forensic Agent with Compiled Tool-use Trajectories), which learns an image-conditioned tool-use policy for forensic analysis. Instead of applying a fixed detector, FACT decides which forensic tools to call, interprets the returned evidence, and stops when sufficient evidence has been collected. FACT follows an Evolve--Distill--Refine pipeline: it evolves an execution-verified forensic skill, compiles the skill into action--observation tool-use trajectories, distills them into a compact agent, and refines the policy with cost-aware GRPO. Across two internal and four public benchmarks, FACT achieves the best performance among all compared methods, including on recent unseen generators, deepfakes, and manipulated images.

# FACT 论文详细总结

## 1. 论文的核心问题与整体含义

- **研究问题**：AI 生成图像检测正进入“开放世界”场景。新的图像生成器（如 GPT-Image、Nano Banana、OmniGen2 等）生成的图像越来越逼真，传统视觉伪影难以识别；不同生成器家族适用的取证线索差异很大，固定检测器难以跨生成器泛化。
- **核心思想**：不应再依赖单一固定检测器，而是学习一种**图像条件化的工具使用策略**：对每一张待检测图像，智能体自行决定调用哪些取证工具、如何解释返回的证据，以及在证据充分时停止并给出 real/AI 判断。
- **整体含义**：将 AI 图像检测从“训练一个更强的分类器”重新定义为“学习一个取证调查过程”，强调证据获取与停止决策应当联合优化，而非预先固定证据组合。

## 2. 论文提出的方法论

### 2.1 问题形式化

- 给定图像 \(x\)，构建取证工具箱 \(U\)，包含冻结的模型级专家和轻量信号级探针。
- 智能体策略 \(\pi_\theta\) 在时间步 \(t\) 观察历史 \(h_t=(x,a_1,o_1,\dots,a_{t-1},o_{t-1})\)，然后选择调用工具 \(a_t\in U\) 获取观测 \(o_t\)，或停止并输出最终判断 \(\hat y \in \{\text{real},\text{AI}\}\)。
- 完整轨迹为 \(\tau=(x,a_1,o_1,\dots,a_T,o_T,\hat y)\)，采集成本为 \(C(\tau)=\sum_{a_t\in U} c(a_t)\)，其中 \(c(a_t)\) 是归一化工具成本。

### 2.2 取证工具箱构建

- **模型级专家（5 个）**：
  - SDAIE：基于相机元数据摄影先验的检测器。
  - Community Forensics：跨数千个生成器训练的判别模型。
  - AIDE：语义特征 + 高频/低频证据。
  - SIDA：多模态推理与文本解释。
  - Veritas：模式感知规划与自反思的深度伪造检测器。
- **信号级探针（8 个）**：
  - FFT 和相位统计：频谱行为。
  - 小波和 Laplacian 分析：多尺度纹理。
  - 噪声残差和 JPEG 分析：残差与压缩一致性。
  - 梯度统计和局部 patch 一致性：局部结构规律性。
- 这些工具捕捉不同类型取证证据，供智能体按需调用。

### 2.3 三阶段训练流程：Evolve–Distill–Refine

#### Stage I：工具使用技能演化（Skill Evolution）

- 使用通用大模型 \(M_G\)（论文中用 GPT-5.1）分析带标签图像，借助工具箱进行取证，并维护一个文本形式的取证技能 \(S\)。
- 每次更新时，采样一批带标签图像 \(B_r\)，当前技能 \(S_r\) 指导模型进行工具调用并产生预测；随后揭示标签，形成错误摘要 \(D_r\)。
- 模型提出候选修订技能 \(\tilde S_r = \text{UpdateSkill}_{M_G}(S_r, D_r)\)。
- 在独立验证批次 \(V_r\) 上重跑工具使用过程，计算验证准确率 \(J(S;V_r)\)。
- **重放检查（replay check）**：仅当 \(J(\tilde S_r;V_r) > J(S_r;V_r)\) 时才接受修订：
  \[
  S_{r+1} = \begin{cases}
  \tilde S_r, & J(\tilde S_r;V_r) > J(S_r;V_r),\\
  S_r, & \text{否则}.
  \end{cases}
  \]
- 输出为经过执行验证的取证技能 \(S^\star\)。

#### Stage II：轨迹蒸馏（Trajectory Distillation）

- 固定技能 \(S^\star\)，让通用模型 \(M_G\) 在真实工具环境中与工具箱交互，为每张训练图像生成动作—观察轨迹。
- 轨迹包括工具调用、返回的工具输出、以及最终监督标签。
- 将每条轨迹序列化为训练序列，其中工具输出作为上下文但不作为预测目标。
- 对紧凑策略 \(\pi_\theta\)（论文中用 Qwen3-VL-8B-Instruct）进行监督微调（SFT）：
  \[
  L_{\text{SFT}} = -\frac{1}{\sum_{i,t} m_{i,t}} \sum_{i,t} m_{i,t} \log \pi_\theta(z_{i,t} \mid x_i, z_{i,<t})
  \]
  其中 \(m_{i,t}\) 仅对智能体生成 token（工具调用、停止决策、最终答案）为 1。

#### Stage III：成本感知的 GRPO 精炼

- 对每个训练图像采样一组 \(K\) 条完整轨迹。
- 每条轨迹的奖励定义为：
  \[
  R(\tau_i^k, y_i) = R_{\text{task}}(\hat y_i^k, y_i) - \lambda C(\tau_i^k) - R_{\text{format}}(\tau_i^k) - R_{\text{invalid}}(\tau_i^k)
  \]
  - \(R_{\text{task}}\)：正确答案 +1，错误 −1，不确定 0，无有效最终答案 −1.2。
  - \(C(\tau)\)：累计工具采集成本。
  - \(R_{\text{format}}\)：格式错误惩罚 0.2。
  - \(R_{\text{invalid}}\)：无效工具调用惩罚 0.2 \(\times N_{\text{invalid}}\)。
- 计算组相对优势 \(A_i^k\)，并进行带 clip 的 GRPO 优化，同时加入 KL 正则项 \(\beta D_{\text{KL}}(\pi_\theta \|\pi_{\text{ref}})\)。
- 该阶段主要教会智能体“额外一次工具调用是否值得其成本”，而非从零学习工具使用。

### 2.4 推理阶段

- 测试时仅使用训练后的紧凑智能体 \(\pi_\theta\) 和固定工具箱。
- 每一步可调用工具或输出 Stop；返回的观察加入历史并用于选择下一步动作。
- 停止后输出 real/AI 判断和简要理由。
- 技能演化组件与通用模型仅在训练阶段使用。
