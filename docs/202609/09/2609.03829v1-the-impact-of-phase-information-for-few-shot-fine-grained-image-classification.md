## 摘要
少样本细粒度图像分类（FSFGIC）旨在利用有限的标注样本对相似图像进行分类。本工作强调了相位信息在捕捉图像内结构关系方面关键但尚未被充分利用的作用。本研究引入了一种新颖的即插即用振幅-相位集成（API）模块，该模块有效结合局部和全局频率的振幅与相位信息，以获得更全面的特征描述符。此外，提出了一种专用网络 PSF-Net，用于自适应融合基于相位的空间和频率信息以进行少样本细粒度图像分类。所设计的 PSF-Net 可以轻松集成到标准的片段式训练架构中，从零开始端到端训练。在五个公开数据集上的大量实验表明，该方法优于现有最先进的基准。

## Abstract
Few-shot fine-grained image classification (FSFGIC) aims to classify similar images with limited labeled examples. This work highlights the critical yet underutilized role of phase information in capturing structural relationships within an image. This study introduces a novel plug-and-play amplitude-phase integration (API) module that effectively combines local and global frequency amplitude and phase information for obtaining more comprehensive feature descriptors. Additionally, a dedicated network, named PSF-Net, is proposed that adaptively fuses phase-based spatial and frequency information for FSFGIS. The designed PSF-Net can be easily integrated into standard episodic training architectures for end-to-end training from scratch. Extensive experiments on five public datasets demonstrate that the method outperforms existing state-of-the-art benchmarks.

## 1. 论文的核心问题与整体含义

- **研究背景**：少样本细粒度图像分类（FSFGIC）需要在每类仅 1 或 5 个标注样本的条件下，区分高度相似的子类别（如不同鸟类、犬种、车型）。
- **核心问题**：现有方法主要依赖幅度（amplitude）信息，忽视了**相位（phase）信息**在刻画图像结构关系中的关键作用。相位记录了不同频率分量的空间位置关系，对细粒度目标的几何布局和局部结构具有重要判别力。
- **动机**：论文通过示例指出，现有空间-频率融合方法（如 BDFR-Net）因未利用相位信息，容易将不同类别误判为同一类，或将同一类样本误判为不同类。为此，提出显式建模相位信息的框架，以提升少样本细粒度识别性能。

## 2. 论文提出的方法论

- **整体框架 PSF-Net**：包含三个主要模块：
  - **振幅-相位集成（API）模块**：提取并融合局部与全局频率的幅度和相位特征。
  - **空间-频率融合模块**：将频率增强特征注入浅层空间特征，保留结构线索。
  - **相似度测量模块**：基于双向交叉注意力重构计算支持集与查询集之间的距离。

- **API 模块的关键技术细节**：
  - **局部频率特征提取**：采用多尺度（半径 \(r=\{0.30,0.22,0.16\}\)）和多方向（8 个方向）的正弦-余弦高斯核，对输入图像逐通道进行卷积，得到实部和虚部响应；随后转换为极坐标形式的局部幅度和单位相位表示。
  - **局部频带选择**：使用可学习截止半径 \(\kappa^{lo}_m,\kappa^{hi}_m\) 和平滑参数 \(\tau_m\) 构造频带权重 \(\Omega^{loc}_m\)，对幅度和相位进行加权，以增强细纹理和细微形状差异。
  - **全局频率特征提取**：对每个通道进行二维实 FFT，得到幅度谱 \(A_c(\omega)\) 和相位谱 \(U_c(\omega)\)；采用中频带通滤波器 \(H(\omega)\)（保留径向频率 \(0.05\le\rho(\omega)\le0.35\)）提取具有判别力的全局结构信息；相位谱还经过幅度调制 \(\delta_c(\omega)\) 进行加权。
  - **逆变换**：处理后的全局幅度和相位通过 irFFT2 变换回空间域。
  - **局部-全局自适应融合**：对每个通道计算幅度和相位在空间上的平均绝对能量，经对数压缩和可学习偏置后使用 Softmax 生成局部/全局权重；最终得到融合后的幅度描述符 \(A^{fus}_c\) 和相位描述符 \(\Phi^{fus}_c\)，再通过卷积块 \(\Lambda_1,\Lambda_2\) 处理后拼接为频率增强特征 \(\Theta_f\)。

- **空间-频率融合模块**：
  - 将浅层空间特征 \(\Theta_s\) 与频率特征 \(\Theta_f\) 拼接，经 MLP 和 Sigmoid 得到通道权重 \(\eta\)；
  - 同时利用余弦相似度 \(\varsigma_1\)、空间均值 \(\varsigma_2\)、频率均值 \(\varsigma_3\) 构造空间注意力图 \(T\)；
  - 最终注入特征为 \(\Theta_{inj}=\Theta_f\odot\eta\odot T\)，并与原始空间特征残差融合：\(\Theta_{fus}=\lambda\Theta_s+\Theta_{inj}\)。

- **相似度测量模块**：
  - 将支持集和查询集特征图展平为 token；
  - 通过双向交叉注意力头对查询 token 和支持 token 进行互相重构；
  - 根据重构误差计算距离 \(d_n\)，并通过 softmax 得到分类概率。

- **训练方式**：支持端到端从零训练，可集成到标准片段式（episodic）训练架构中。

## 6. 论文的主要结论与发现

- **相位信息对少样本细粒度分类至关重要**：显式建模相位能够补充幅度和空间特征之外的判别线索，提升高度相似子类的可分性。
- **提出的 API 模块和 PSF-Net 有效**：在五个公开数据集、两种骨干、1-shot 和 5-shot 任务上均取得最佳结果，超过现有 SOTA 方法。
- **融合深度选择关键**：在骨干较浅位置（\(\Lambda_2\)）注入频率特征效果最佳，说明细粒度判别信息集中在局部部件级结构，过深语义抽象会削弱相位表达力。
- **频率成分互补**：完整模型（幅度+相位）优于仅幅度或仅相位模型，证明二者具有互补性。
- **多尺度、多方向局部频率采样**：适度增加半径尺度可提升性能，但方向数过多或半径过密会引入冗余噪声和过拟合风险；默认配置 \(r=\{0.30,0.22,0.16\}, o=8\) 在容量与泛化之间取得较好平衡。
