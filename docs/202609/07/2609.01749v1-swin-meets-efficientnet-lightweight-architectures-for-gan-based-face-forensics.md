## 摘要
现代生成模型（如 GAN、扩散架构和自回归系统）如今能够生成与真实照片几乎无法区分的人脸图像。这一能力使伪造图像检测日益困难，引发了人们对身份盗窃、欺诈和虚假信息传播的严重担忧。我们的研究特别关注基于 GAN 生成的合成人脸，这些人脸是许多人脸中心深度伪造的基础，并研究仅使用图像分析的高效检测方法。现有检测系统主要依赖卷积神经网络（CNN）或全局视觉 Transformer。虽然 CNN 擅长识别基于纹理的局部特征，但在更广泛的上下文理解方面存在困难。传统视觉 Transformer（ViT）模型能够有效捕捉长程结构，但需要大量计算资源。我们的工作探索了基于 Swin Transformer 的三种实现架构：从头训练的小型 Swin Transformer、经 ImageNet-1K 预训练并适配为二分类的 Swin-Tiny 和 Swin-Small 模型，以及一种将 EfficientNet-B0 的卷积处理与 Swin Transformer 后端相结合的新型混合架构。我们使用 140K Real and Fake Faces 数据集评估所有模型，该数据集包含 StyleGAN 生成的假人脸以及来自 Flickr 和 DFDC 的真实图像，并划分了均衡的训练、验证和测试集。EfficientNetB0+Swin 混合模型在 5,000 张测试图像上实现了 99% 的准确率和 99.44% 的召回率，优于纯 Swin 变体以及该数据集上先前的仅 CNN 基线。我们的结果表明，将分层 CNN 特征与移位窗口自注意力相结合，为检测 GAN 生成的合成人脸提供了一种高效且计算轻量的方法。

## Abstract
Modern generative models, such as GANs, diffusion architectures, and autoregressive systems, now produce facial images that are nearly indistinguishable from authentic photographs. This capability makes detecting forged images increasingly difficult, raising serious concerns about identity theft, fraud, and misinformation campaigns. Our research focuses specifically on GAN-generated synthetic faces, which underpin many face-centric deepfakes, and investigates efficient detection approaches using image analysis alone. Existing detection systems rely heavily on either convolutional neural networks (CNNs) or global vision transformers. While CNNs excel at identifying texture-based local features, they struggle with broader contextual understanding. Traditional Vision Transformer (ViT) models can capture long-range structures effectively, but demand substantial computational resources. Our work explores Swin-Transformer-based architectures across three implementations: a compact Swin Transformer trained from the ground up, ImageNet-1K pre-trained Swin-Tiny and Swin-Small models adapted for binary classification, and a novel hybrid combining EfficientNet-B0's convolutional processing with a Swin Transformer backend. We evaluated all models using the 140K Real and Fake Faces dataset, which includes StyleGAN-generated fake faces alongside authentic images from Flickr and DFDC, with balanced splits for training, validation, and testing. The EfficientNetB0+Swin hybrid achieved 99% accuracy and a 99.44% recall on 5,000 test images, outperforming both pure Swin variants and a previous CNN-only baseline on this dataset. Our results suggest that combining hierarchical CNN features with shifted-window self-attention provides an efficient and computationally lightweight method for detecting GAN-generated synthetic faces.

- **核心问题**：如何在不依赖视频时序信息或多模态元数据的前提下，仅通过单张人脸图像，高效且轻量地检测 **GAN 生成的合成人脸**。
- **现有方法局限**：
  - CNN 类检测器擅长捕捉局部纹理伪影，但缺乏全局上下文建模能力。
  - 全局 Vision Transformer（ViT）能建模长程结构，但计算量与内存消耗较高，依赖大规模预训练。
- **整体含义**：探索 **Swin Transformer** 及其与 CNN 的混合架构，在保持较低计算成本的同时，兼顾局部伪影与全局人脸一致性，为资源受限的 GAN 合成人脸取证提供可行方案。

## 2. 论文提出的方法论

### 2.1 问题形式化

- 输入为裁剪后的 RGB 人脸图像 \(I \in \mathbb{R}^{H \times W \times 3}\)。
- 标签 \(y \in \{0,1\}\)：\(y=1\) 表示 GAN 生成人脸，\(y=0\) 表示真实人脸。
- 检测器输出概率 \(p_\theta(I)\)，采用标准二元交叉熵损失训练：

\[
\mathcal{L}(\theta)=-\frac{1}{|D|}\sum_{(I,y)\in D}\left[y\log p_\theta(I)+(1-y)\log(1-p_\theta(I))\right]
\]

### 2.2 Swin Transformer 骨干网络

- Swin 将输入图像划分为非重叠 patch，线性投影为 token。
- 使用 **窗口多头自注意力（W-MSA）** 与 **移位窗口多头自注意力（SW-MSA）** 交替计算，在控制计算复杂度约为线性增长的同时引入跨窗口交互。
- 通过 patch merging 构建多尺度特征金字塔：浅层捕捉皮肤纹理、边界伪影等局部线索；深层建模眼睛、嘴巴、背景等区域间全局一致性。
- 最终 token 经全局平均池化后映射为标量 logit，通过 sigmoid 得到 \(p_\theta(I)\)。

### 2.3 三种模型变体

#### （1）Swin Base（从头训练）

- 紧凑 Swin 模型，输入分辨率 \(128 \times 128\)，patch size \(4 \times 4\)，window size \(8\)。
- 完全从零开始在 GAN 数据上训练，不依赖 ImageNet 预训练。
- 作用：作为 Swin 从零训练能力基线，评估迁移学习与混合架构带来的增益。

#### （2）Swin Transfer（ImageNet 预训练微调）

- 使用标准 **Swin-Tiny** 和 **Swin-Small** 骨干，输入分辨率 \(224 \times 224\)，patch size \(4\)，window size \(7\)。
- 将原始 ImageNet 分类头替换为单 sigmoid 输出单元，并在伪造检测数据上微调所有层。
- 用于分析 Swin 家族中模型容量与性能的关系。

#### （3）Hybrid EfficientNet + Swin 混合架构

- 输入分辨率 \(384 \times 384\)，使用 ImageNet-1K 预训练的 **EfficientNet-B0** 作为卷积前端。
- 从 EfficientNet-B0 提取两类特征：
  - **中间层特征图**（block6a_expand_activation）：保留空间细节与纹理信息，划分为 \(2 \times 2\) patch，线性嵌入后输入浅层 Swin 栈，window size 2，8 个注意力头。
  - **最终层特征图**：经全局平均池化生成紧凑 CNN 描述向量。
- Swin 输出经全局平均池化后与 CNN 描述向量拼接，再经全连接层与 sigmoid 输出。
- 优点：
  - EfficientNet 提取局部伪影与噪声模式；
  - Swin 对中间特征图建模跨区域上下文；
  - 自注意力在较低空间分辨率上进行，token 数较少，计算成本低；
  - 利用 ImageNet 预训练提升数据效率。
