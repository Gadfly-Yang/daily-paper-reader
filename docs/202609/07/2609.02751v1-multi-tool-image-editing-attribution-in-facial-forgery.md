## 摘要
随着生成式人工智能工具日益强大且易于使用，人们可以借助提示轻松编辑人像图像，这使得图像编辑归因任务变得必要；该任务根据给定图像预测所涉及的编辑工具。现有归因方法基于单工具假设，只能归因于特定编辑工具，难以处理更复杂且日益常见的多工具编辑场景，其中不同编辑工具留下的伪影相互叠加、复合。为填补这一空白，我们探索了多工具图像编辑归因（MIEA），旨在识别多工具编辑人脸图像中所涉及的多个编辑工具。为模拟人脸图像上的真实编辑操作，我们构建了一个新数据集 MultiEdit，包含50万余张编辑人脸图像，涵盖六类支持换脸（Deepfake）及多种人脸增强的编辑工具。受数据分析发现的启发，我们设计了 DPEC，一种多工具归因方法，在基于误差的课程学习策略支持下，能够从空间域和频率域中捕捉可区分的、具有局部感知的编辑工具痕迹。实验表明，针对最多五步编辑的人脸图像，DPEC 优于九种方法。

## Abstract
As generative AI tools become increasingly powerful and easy to use, people can easily edit portrait images with a prompt, necessitating the task of image editing attribution, which predicts the involved editing tools from the given image. Existing attribution methods hold the single-tool assumption and can only attribute a specific editing tool, but struggle to handle the more complex and increasingly common multi-tool editing scenarios, where artifacts left by different editing tools are composite and overlapped. To address this gap, we explore Multi-Tool Image Editing Attribution (MIEA), which aims to identify multiple editing tools involved in a multi-tool edited facial image. To simulate the real-life editing operations on facial images, we then construct a new dataset, MultiEdit, which contains 500k+ edited facial images and covers six types of editing tools that support face swapping (Deepfake) and various facial enhancements. Inspired by the findings from data analysis, we design DPEC, a multi-tool attribution method that can capture distinguishable, locality-aware editing tool traces from both spatial and frequency domains with the support of an error-based curriculum learning strategy. Experiments show \Method\ outperforms nine methods for facial images edited in at most five steps.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：随着生成式 AI（GAN、扩散模型等）的普及，普通用户可以通过简单的提示词对人像进行高度逼真的编辑。据论文引用，社交媒体上 71% 的图像已为 AI 生成或 AI 编辑，这带来了虚假新闻、名誉损害、学术造假等滥用风险。
- **核心问题**：现有图像编辑归因（attribution）方法均假设单工具编辑场景，即一张图像只由一种编辑工具处理过。然而现实中，一幅精修人像往往经过多个工具、多个步骤的依次编辑（如换脸 → 美肤 → 化妆 → 瘦脸），不同工具留下的伪影相互叠加、覆盖，导致单工具归因方法失效。
- **任务定义**：论文提出**多工具图像编辑归因（MIEA）**任务，目标是根据给定的最终编辑图像，识别其完整编辑链中涉及的所有编辑工具（不再局限于最后一步使用的工具）。
- **整体含义**：MIEA 旨在提升图像取证的透明度，完整还原编辑工作流，避免恶意操作被后续良性编辑掩盖，从而增强对数字图像真实性的溯源与问责能力。

## 2. 方法论（核心思想、关键技术、算法流程）

论文提出 **DPEC（Dual-domain Patchwise Enhancement with Curriculum learning）** 方法，将 MIEA 形式化为多标签分类问题：给定编辑图像 \(I_s\)，模型预测工具集 \(\mathcal{T}\) 中每个工具是否被使用。

### 2.1 整体框架

DPEC 包含两大核心模块：

- **Patchwise Feature Enhancement（PFE，双域 Patch 级特征增强）**
- **Error-based Curriculum Learning（ECL，基于误差的课程学习）**

### 2.2 PFE 模块

PFE 的设计动机来自论文数据分析中的两个发现：

- **Q2 发现**：不同编辑工具在空间域和频域具有互补的可区分性（有些工具空间域相似但频域差异大，反之亦然）。
- **Q3 发现**：同一编辑工具在不同面部区域表现出不同的编辑强度，因此需要局部感知（locality-aware）的特征提取。

PFE 的具体流程如下：

1. **滑动窗口 DCT（SWDCT）**：对输入图像 \(I_s \in \mathbb{R}^{H \times W \times C}\) 使用窗大小为 \(h \times w\)、步长为 \(d\) 的滑动窗口进行 2D 离散余弦变换，得到频域特征图 \(I_f = \{I_{f1}, I_{f2}, \dots, I_{fN}\}\)，其中 \(N = \left(\frac{H-h}{d}+1\right) \times \left(\frac{W-w}{d}+1\right)\)。
2. **双域特征提取**：分别用两个独立骨干网络（均使用 Xception 前三层）提取空间特征 \(F_s\)（从原图）和频域特征 \(F_f\)（从 \(I_f\)）。
3. **位置编码**：对展平后的 \(F_s\) 和 \(F_f\) 加入可学习位置编码，得到 \(F_{sp}\) 和 \(F_{fp}\)，增强位置感知能力。
4. **双向 Patch 级交叉注意力**：分别为空间特征关注频域特征，以及频域特征关注空间特征：

\[
\operatorname{Attn}(Q, K, V) = \operatorname{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V
\]

\[
F'_s = F_s + \operatorname{Reshape}(\operatorname{Attn}(Q_{F_{sp}}, K_{F_{fp}}, V_{F_{fp}}))
\]

\[
F'_f = F_f + \operatorname{Reshape}(\operatorname{Attn}(Q_{F_{fp}}, K_{F_{sp}}, V_{F_{sp}}))
\]

5. **特征融合**：将增强后的空间与频域特征融合，送入多标签分类器，输出每个工具的参与概率。

### 2.3 ECL 模块

ECL 的设计动机来自 **Q4 发现**：编辑步数增加并不线性增加感知损失（LPIPS），后续编辑会稀释、覆盖前期痕迹，因此不同步数的样本难度呈非线性关系。ECL 基于自步学习（Self-Paced Learning, SPL）思想：

1. **数据划分**：将训练集按编辑步数分为 \(M=5\) 个子集（1 到 5 步）。
2. **动态采样权重**：每个子集 \(S_i\) 分配采样概率 \(p_i\)（初始均分 0.2）。每轮训练结束后，在验证集上计算各子集的平均错误率 \(e_i\)。
3. **权重更新**：使用多项式 SPL 正则项（\(t=3\)）计算闭式最优解：

\[
p_i^* = \begin{cases}
\left(1 - \frac{e_i}{\lambda}\right)^{1/(t-1)}, & e_i < \lambda \\
0, & e_i \geq \lambda
\end{cases}
\]

其中 \(\lambda\) 为年龄参数（初始 0.5，每轮 +1）。随着训练推进，模型从简单样本（少步编辑）逐步过渡到困难样本（多步编辑）。

## 6. 主要结论与发现

1. **DPEC 总体最优**：平均 Acc-S 达 92.93%，平均 Acc-T 达 98.56%；在 5 步编辑的最困难样本上 Acc-S 仍达 87.40%。
2. **多步编辑确实加剧检测困难**：所有方法随编辑步数增加而性能下降，Q1 分析也证实多步编辑会显著降低单工具检测器的 recall。
3. **双域特征互补**：Q2 数据分析和 PFE 消融实验均表明空间域和频域特征对 MIEA 均有不可替代的作用。
4. **局部感知重要**：SWDCT 的滑动窗口形式比全局 DCT/DWT 显著更优（优势 7-15%）。
5. **课程学习有效**：ECL 在困难样本上的增益尤为明显（移除 ECL 后 5 步 Acc-S 从 87.40% 降至 85.68%）。
6. **可迁移到二分类检测**：DPEC 在 FF++ 域内与跨域（Celeb-DF）检测上均与先进基线竞争。
7. **对 JPEG 压缩有一定鲁棒性**：虽性能下降，但仍优于 F3-Net 和 NPR。
8. **顺序预测挑战巨大**：序列恢复的 EM 平均仅 12.64%，表明工具顺序前景不确定。

## 7. 优点（方法/实验亮点）

- **新任务定义清晰**：MIEA 为多工具编辑归因提供了正式的问题形式化，填补了现有单工具假设的空白。
- **数据集规模大且设计规范**：50万+ 图像、6 类工具、严格质量控制（SSIM + Qwen3-VL 双重过滤）、身份隔离的数据划分。
- **数据分析驱动方法设计**：Q1-Q4 四个前置分析（检测退化、双域差异、区域异质性、非线性难度）为方法提供了坚实的实证依据，使设计有很强的说服力。
- **PFE 双域 Patch 级交叉注意力**：将空间域与频域互补信息通过局部注意力机制融合，兼顾了工具间差异和区域内差异。
- **ECL 课程学习符合实际**：针对多步编辑痕迹被覆盖的现象，以误差反馈动态调整采样权重，从易到难逐步训练。
- **较强的实验广度**：涵盖多步性能、跨域检测、压缩鲁棒性、消融、可视化以及超参数敏感性。
