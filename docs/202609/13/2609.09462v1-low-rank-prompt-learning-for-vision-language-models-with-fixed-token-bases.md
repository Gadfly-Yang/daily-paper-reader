## 摘要
提示学习通过以学习到的连续上下文向量替代手写模板，使 CLIP 适应下游识别任务；在上下文优化（CoOp）中，这些向量构成稠密提示矩阵 $\mathbf{P}\in\mathbb{R}^{m\times d}$，仅利用每类少量样本训练。我们研究该矩阵是否过参数化，将其分解为 $\mathbf{P}=\mathbf{B}\mathbf{A}$，从而将可训练提示参数从 $md$ 削减至 $r(m+d)$，且在 token 侧因子 $\mathbf{B}$ 固定后降至 $rd$。在七个少样本基准和两个 CLIP 骨干网络上，低秩提示以远更少的参数达到或超越稠密 CoOp，尤其在低样本的基类到新类泛化上增益最显著。我们进一步发现 token 侧因子完全无需学习：将 $\mathbf{B}$ 固定为高斯、正交、SVD 派生甚至随机基，仅训练嵌入侧因子 $\mathbf{A}$，即可与完全可训练的分解持平；并且源域训练得到的 $\mathbf{B}$ 相比随机 $\mathbf{B}$ 没有任何优势。提示因子不对称性和局部更新空间维度差距揭示了为何固定 $\mathbf{B}$ 远不如固定 $\mathbf{A}$ 限制性强；仅基于光滑性的保证即可证明在固定 $\mathbf{B}$ 上优化 $\mathbf{A}$ 收敛。在 CLIP 提示设置中，嵌入侧系数承担适配，而 token 基可以简单固定。

## Abstract
Prompt learning adapts CLIP to downstream recognition by replacing hand-written templates with learned continuous context vectors, which in Context Optimization (CoOp) form a dense prompt matrix $\mathbf{P}\in\mathbb{R}^{m\times d}$ trained from only a few examples per class. We study whether this matrix is over-parameterized by factorizing it as $\mathbf{P}=\mathbf{B}\mathbf{A}$, which cuts the trainable prompt parameters from $md$ to $r(m+d)$, and to $rd$ once the token-side factor $\mathbf{B}$ is fixed. Across seven few-shot benchmarks and two CLIP backbones, low-rank prompts match or improve dense CoOp at far fewer parameters, with the clearest gains on low-shot base-to-new generalization. We then find that the token-side factor need not be learned at all: fixing $\mathbf{B}$ to a Gaussian, orthogonal, SVD-derived, or even random basis and training only the embedding-side factor $\mathbf{A}$ stays on par with the fully trainable factorization, and a source-trained $\mathbf{B}$ offers no advantage over a random one. A prompt-factor asymmetry and a local update-space dimension gap show why fixing $\mathbf{B}$ is far less restrictive than fixing $\mathbf{A}$, and a smoothness-only guarantee certifies that optimizing $\mathbf{A}$ over a fixed $\mathbf{B}$ converges. In the CLIP prompt setting, the embedding-side coefficients carry the adaptation while the token basis can simply be fixed.

## 2. 论文提出的方法论

- **核心思想**：将密集 CoOp 提示矩阵替换为低秩乘积：
  \[
  \mathbf{P}=\mathbf{B}\mathbf{A},\quad \mathbf{B}\in\mathbb{R}^{m\times r},\ \mathbf{A}\in\mathbb{R}^{r\times d},\ r\ll \min(m,d)
  \]
  其中 \(\mathbf{B}\) 在 token 位置空间混合 \(r\) 个潜在成分，\(\mathbf{A}\) 在 CLIP 文本嵌入空间选择方向。

- **参数削减**：参数从 \(md\) 降至 \(r(m+d)\)（联合训练），固定 \(\mathbf{B}\) 后降至 \(rd\)。以 \(m=16,d=512,r=4\) 为例：\(8192\to 2112\to 2048\)；固定 \(\mathbf{A}\) 仅为 \(mr=64\) 作为对照。

- **三种训练模式**：
  - 联合训练 \(\mathbf{B}\) 和 \(\mathbf{A}\)；
  - 固定 \(\mathbf{B}\)，仅训练 \(\mathbf{A}\)（主要模式）；
  - 固定 \(\mathbf{A}\)，仅训练 \(\mathbf{B}\)（对照，证明因子不可互换）。

- **初始化设计**：
  - 联合分解：对采样稠密提示 \(\mathbf{P}_0\) 做平衡截断 SVD 初始化因子。
  - 固定基消融：\(\mathbf{A}_0=\mathbf{B}_{\text{fixed}}^\dagger \mathbf{P}_0\)（最小二乘投影），保证初始乘积是 \(\mathbf{P}_0\) 在所选基上的投影。
  - 固定基类型：高斯、缩放正交、SVD 派生、已学习冻结基。

- **理论支撑**：
  - **提示因子不对称性（线性替代假设）**：固定正交 \(\mathbf{B}\) 的残差是 token 空间 \(\mathbb{R}^m\) 上的投影；固定正交 \(\mathbf{A}\) 的残差是嵌入空间 \(\mathbb{R}^d\) 上的投影。期望残差比例为 \((1-r/m)\) vs \((1-r/d)\)，因 \(m\ll d\)，固定 \(\mathbf{B}\) 的误差小得多。
  - **局部更新空间维度差**：固定 \(\mathbf{B}\) 训练 \(\mathbf{A}\) 的更新空间维度为 \(rd\)；固定 \(\mathbf{A}\) 训练 \(\mathbf{B}\) 的更新空间维度为 \(mr\)；比值为 \(d/m=32\)（在 \(m=16,d=512\) 下）。
  - **收敛保证**：在方向光滑性和下界假设下，固定 \(\mathbf{B}\) 上对 \(\mathbf{A}\) 做梯度下降/随机梯度下降可收敛到一阶稳定点，速率 \(O(1/T)\) 或 \(O(T^{-1/2})\)。

## 6. 论文的主要结论与发现

- **低秩提示有效且高效**：低秩分解以约四分之一参数达到或超越稠密 CoOp，尤其在 1-shot 和 4-shot 下的未见类泛化上有显著提升；随着样本增加，优势有所减弱但仍保持相当。
- **token 侧因子可固定**：将 \(\mathbf{B}\) 固定为高斯、正交、SVD 派生甚至随机基，仅训练 \(\mathbf{A}\)，性能与完全可训练的分解几乎无差别；许多设置下固定基甚至优于可训练版本。
- **迁移控制证明 \(\mathbf{B}\) 无任务特异性**：冻结 \(\mathbf{B}\) 训练 \(\mathbf{A}\) 平均约 89%，而冻结 \(\mathbf{A}\) 训练 \(\mathbf{B}\) 仅约 78%；源数据集训练的 \(\mathbf{B}\) 与随机 \(\mathbf{B}\) 相比没有任何优势。
- **因子几何解释**：\(\mathbf{B}\) 跨数据集、shot、rank 高度对齐（子空间重叠 0.86–0.89），但跨种子对齐低（0.41）；\(\mathbf{A}\) 和 \(\mathbf{B}\mathbf{A}\) 对齐弱。说明 \(\mathbf{B}\) 主要受初始化影响，训练移动很小。
- **理论结论**：固定 \(\mathbf{B}\) 比固定 \(\mathbf{A}\) 的限制小得多，嵌入侧系数 \(\mathbf{A}\) 承载了主要适配能力。

## 7. 优点

- **方法简洁有效**：低秩分解直接减少参数，且固定随机基的做法进一步降低训练成本，实现简单。
- **理论与实验结合**：提供因子不对称性、更新空间维度差和收敛性保证，解释

了为何固定 token 侧因子 \(\mathbf{B}\) 在理论上具有更小的误差上界和更大的可行更新空间，为实验观察到的高性能提供了合理解释。

- **实验设计严谨**：设置 Dense-4 参数匹配对照、冻结 \(\mathbf{A}\) 训练 \(\mathbf{B}\) 的不可互换对照、以及跨数据集迁移控制，排除了多种替代解释，使“\(\mathbf{B}\) 可固定”的结论更具说服力。

## 8. 缺点与局限性

- **模型覆盖有限**：仅在 CLIP 的 ViT-B/16 和 RN50 上验证，未涉及更大规模 CLIP 模型（如 ViT-L/14）或其他视觉–语言模型（如 ALIGN、OpenCLIP），结论的模型泛化性有待检验。
- **统计严谨性不足**：每个设置仅使用 3 个随机种子，报告均值与标准差，未进行显著性检验或等价检验；部分数据集（如 FGVC Aircraft）标准差较大，性能差异可能落在噪声范围内。
- **计算成本未报告**：作者明确指出参数减少不等同于实际训练时间、峰值显存或总计算开销降低；固定 \(\mathbf{B}\) 虽然减少了可训练参数，但前向计算仍需完整矩阵乘法，实际加速有限。
- **理论假设较强**：收敛性保证依赖于方向光滑性和下界假设，这些假设在 CLIP 文本编码器诱导的非凸损失景观中未必严格成立，理论结果更多是启发性而非精确刻画。
- **随机基机制解释不完整**：虽然几何分析显示 \(\mathbf{B}\) 跨数据集对齐高而跨种子对齐低，但为什么随机固定基足以支持高精度适配，仍缺乏深层机理解释；且 \(\mathbf{B}\) 受初始化影响较大，表明初始化选择可能含有未被充分讨论的隐式正则。
- **任务范围偏窄**：实验集中在图像分类的少样本适配，未涉及检测、分割、视频理解等更复杂的下游任务，低秩提示在更广泛视觉任务中的适用性未经验证。

## 9. 未来工作方向

- **扩展到更多预训练模型与任务**：在更大规模 CLIP 变体、其他视觉–语言模型以及检测/分割等任务上验证低秩提示和固定 \(\mathbf{B}\) 策略的有效性。
- **设计更优的固定基**：探索基于任务分布或文本先验构造 \(\mathbf{B}\) 的方法，替代当前随机或 SVD 派生基，进一步降低初始提示投影误差。
- **结合视觉侧适配**：将低秩文本提示与视觉提示、轻量适配器或 LoRA 式视觉分支结合，形成统一的低秩多模态适配框架。
- **实证计算收益**：测量实际训练吞吐量、显存占用和能耗，明确参数减少带来的硬件级收益，增强该方法在资源受限场景下的实际吸引力。
- **深化理论分析**：放宽收敛性假设，建立更贴近 CLIP 损失景观的理论模型；同时从表示学习的角度解释随机固定基为何能保留足够适配能力。
