## 摘要
小样本学习通常在如下协议下评估：模型先在一个大型辅助数据集上预训练，该辅助数据集的类别与目标片段（episode）中的类别不重叠，但与目标片段来自同一视觉领域。本文考察此类协议是否真正反映低数据学习。我们在八个数据集、三种小样本架构以及多种 way-shot 设置上，系统比较了无预训练、类别不重叠的域内预训练、有监督域外预训练和无标签域外预训练。结果表明，仅靠类别不重叠不足以消除目标领域数据的影响。域内预训练相比无预训练平均提升 33.41 个百分点，而有监督域外预训练提升 23.75 个百分点，揭示了与领域重叠相关的 9.66 个百分点的乐观偏差。尽管在目标领域数据稀缺的应用中域外预训练更为现实，但其有效性在很大程度上取决于源领域与目标领域之间的兼容性。我们进一步表明，有标签的源数据并非严格必需，一种基于增强的无标签策略平均增益达到 27.71 个百分点，与有监督域外预训练的 27.97 个百分点十分接近。最后，我们引入一种基于描述子的源选择策略，在预训练前估计源领域适用性，其与 oracle 选择的中位差距仅为 1.37 个百分点。这些发现强调，需要超越将域内预训练作为默认小样本评估协议的做法，因为在目标领域数据稀缺的现实场景中，这种做法可能高估性能。

## Abstract
Few-shot learning is commonly evaluated under protocols that pre-train a model on a large auxiliary set whose classes are disjoint from the target episodes yet drawn from the same visual domain. This paper examines whether such protocols truly reflect low-data learning. We systematically compare no pre-training, class-disjoint in-domain pre-training, supervised out-of-domain pre-training, and label-free out-of-domain pre-training across eight datasets, three few-shot architectures, and multiple way-shot settings. Our results show that class disjointness alone is insufficient to remove the influence of target-domain data. In-domain pre-training improves over no pre-training by 33.41 percentage points on average, whereas supervised out-of-domain pre-training yields 23.75 percentage points, revealing a 9.66-point optimistic bias associated with domain overlap. Although out-of-domain pre-training is more realistic in applications where target-domain data are scarce, its effectiveness depends strongly on the compatibility between source and target domains. We further show that labeled source data are not strictly required, with an augmentation-based label-free strategy reaching an average gain of 27.71 percentage points and closely matching supervised out-of-domain pre-training at 27.97 percentage points. Finally, we introduce a descriptor-based source-selection strategy that estimates source-domain suitability before pre-training, reaching a median gap of only 1.37 percentage points to oracle selection. These findings highlight the need to move beyond in-domain pre-training as the default few-shot evaluation protocol, since it can overestimate performance in realistic scenarios where target-domain data are scarce.

## 1. 论文的核心问题与整体含义

- **核心问题**：标准小样本学习（FSL）评估协议通常在大型辅助数据集上预训练，辅助集与目标片段类别不重叠，但来自同一视觉域。论文质疑这种“类别不重叠但域重叠”的协议是否真正反映低数据学习能力。
- **问题实质**：类别不重叠并不等于域不重叠。例如 Omniglot 中不同字符仍共享黑白色手写特征，miniImageNet 中存在大量视觉相似、语义相关的类别（如 house finch 与 robin）。模型从预训练中受益于目标域共享的分布特性，使得任务更接近传统 i.i.d. 监督学习，而非真正的低数据跨域学习。
- **现实背景**：在真实应用（罕见物种、医学影像、欺诈检测、卫星图像等）中，目标域标注数据本身稀缺，通常无法获得大量同域标注辅助数据。更现实的是使用域外（OOD）数据预训练，甚至使用无标签外部数据。
- **整体含义**：当前流行的小样本评估协议存在系统性乐观偏差，可能高估模型在真实低数据场景中的性能；需要重新审视预训练假设，推动更现实的域外预训练与源域选择评估框架。

## 2. 方法论

### 2.1 问题形式化与预训练机制

- 定义目标域 `Ptgt(X,Y)` 与源域 `Psrc(X,Y)`。每个 episode 包含支持集 `ST` 和查询集 `QT`，采用 n-way k-shot 设置。
- 少样本预测器表述为：`hθ,T(x) = gT(fθ(x); ST)`，其中 `fθ` 为共享编码器，`gT` 为依赖支持集的分类器（可涵盖 Matching Networks、Prototypical Networks、Relation Networks）。
- 比较三种预训练机制：
  - **No-PT**：无源域预训练，仅用 `ST` 训练。
  - **ID-PT**：同类视觉域、类不重叠预训练，即标准基准协议。
  - **OOD-PT**：源域与目标域在标签空间和输入分布上都不同。
- 引入 **IDA（In-Domain Adaptation）**：在预训练后，仅利用目标支持集 `ST` 进行元学习微调，以减少源-目标不匹配。

### 2.2 乐观偏差形式化

- 借鉴领域自适应理论，给出风险上界关系：
  - `Rtgt(θ) ≲ Rsrc(θ) + 1/2 disc_H(fθ#Psrc(X), fθ#Ptgt(X)) + λθ`
  - 源风险 `Rsrc` 反映源域任务性能；`disc_H` 表示源-目标表示空间差异；`λ` 为残差兼容项。
- 定义：
  - **转移增益**：`ΔR(m,tgt) = Rtgt(θ∅) − Rtgt(θm)`
  - **乐观偏差**：`BR(mID,mOOD,tgt) = ΔR(mID,tgt) − ΔR(mOOD,tgt)`
  - **IDA 增益**：`ΔIDA_R(m,tgt) = Rtgt(θm) − Rtgt(θm^{IDA})`
- 该形式化区分了“类别不重叠”与“域不重叠”：ID-PT 虽然类别不重叠，但因输入分布接近目标域，仍会降低目标元风险，造成乐观评估。

### 2.3 无标签 OOD 预训练策略

- **UCKM（Unsupervised Constrained K-Means）**：使用约束 K 均值对无标签源数据聚类，将每个簇视为伪类。簇需满足最少样本数以保证构 support/query set。以聚类伪标签进行元学习预训练；簇数 `Kc` 为超参。
- **UIAug（Unsupervised Instance-based Augmentation）**：基于实例判别思想，将每张无标签源图像视为独立伪类。对于每个 episode，采样 n 张源图像，生成 k 个增强样本作为支持集，原始图像作为查询集，构造 n-way k-shot 分类任务。无需指定簇数，更简单可扩展。

### 2.4 源域选择策略

- 目标：在预训练前从候选源域池中选出最可能提升目标性能的源，避免对每个源都进行完整预训练和评估。
- 评分函数：`m̂ = argmax_m Score(Psrc^{(m)}, Ptgt)`。
- **个体描述子评分**：对每个源-目标对计算多类相似性描述子（数据集级统计、表示空间重叠、距离紧凑性、重建失配），标准化后，通过离线校准阶段与下游转移增益计算 Pearson 相关 `r(j)`。
- **因子分析综合评分**：将描述子向量堆叠成矩阵，剔除低 KMO 描述子，保留特征值 ≥1 的因子，选择与转移增益相关最强的因子作为综合分数，用于源排序。

## 3. 实验设计

### 3.1 数据集

- 使用 **8 个图像分类数据集**，覆盖异构视觉领域：
  - 音乐符号：Capitan
  - 历史符号：Egyptian
  - 手写字符：Greek、Omniglot、TKH
  - 医学影像：OrganAMNIST
  - 自然图像：CIFAR-FS、MiniImageNet
- MiniImageNet、CIFAR-FS、Omniglot 使用原始类不重叠划分；其余数据集随机划分，约 80% 类用于 meta-training、20% 用于 meta-testing，多次 bootstrap 重新划分。
- 所有图像统一缩放为 40×40 并归一化到 [0,1]，保证跨数据集公平比较。

### 3.2 模型与设置

- 三种代表性度量型元学习架构：
  - Matching Networks
  - Prototypical Networks
  - Relation Networks
- 评估设置：
  - 5-way 与 20-way
  - 1-shot、5-shot、10-shot
- 每个实验运行 4,000 个测试 episodes；预训练（如适用）也运行 4,000 episodes。
- 结果基于 5 次 bootstrap 不同随机种子和类划分取平均。
- 训练超参：初始学习率 1e-3，权重衰减 1e-6，学习率 step size 2,000 episodes；IDA 使用 3 个 1,000-episode 阶段，学习率 1e-4。
- 评估指标：平均查询准确率及其标准差；报告相对 No-PT 的准确率增益 `ΔAcc` 和 IDA 增益 `ΔIDA_Acc`。

- IDA 有无两套设置。
- UCKM 簇数消融：`Kc ∈ {5, 20, 250, 1000}`。
