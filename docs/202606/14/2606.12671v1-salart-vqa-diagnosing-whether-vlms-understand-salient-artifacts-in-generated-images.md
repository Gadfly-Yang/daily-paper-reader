## 摘要
视觉语言模型(VLM)越来越多地被用于检测AI生成图像是否包含可见伪影，然而它们分析此类伪影的能力仍知之甚少。正确的图像级决策可能掩盖重要失败：模型可能正确标记了伪影，却依赖于错误的视觉线索、选择了错误的区域，或描述了图像不支持的缺陷。为直接评估这些行为，我们引入SalArt-VQA，一个用于细粒度显著伪影理解的诊断基准，针对AI生成图像。SalArt-VQA包含950张图像和3,681道人工编写的多选题，涵盖伪影图像、匹配的真实参考图像及成对的生成参考图像。四种对齐的问题类型分别评估存在性检测、语义定位、空间定位和基于证据的缺陷识别，而参考分割测试了在标注缺陷缺失时的校准与弃权能力。在20个VLM上，SalArt-VQA揭示出图像级检测精度所掩盖的失败：最强模型在伪影图像上达到99.37%的检测召回率，但仅53.26%的图像上正确回答了全部四道伪影相关问题。比较伪影图像与无伪影参考图像揭示了灵敏度-校准权衡：灵敏模型常提出无根据的伪影声明，而保守模型主要通过遗漏真实伪影来避免误报。这些结果表明，高伪影检测精度本身并不意味着有根据的伪影理解。SalArt-VQA暴露了这些隐藏的失败模式，并提供了细粒度评估，以判断VLM的伪影声明是否得到局部视觉证据的支持。

## Abstract
Vision-language models (VLMs) are increasingly used to detect whether AI-generated images contain visible artifacts, yet their ability to analyze such artifacts remains poorly understood. A correct image-level decision can still hide important failures: a model may correctly flag an artifact while relying on the wrong visual cue, selecting the wrong region, or describing a defect that the image does not support. To evaluate these behaviors directly, we introduce SalArt-VQA, a diagnostic benchmark for fine-grained SALient ARTifact understanding in AI-generated images. SalArt-VQA contains 950 images and 3,681 human-authored multiple-choice questions spanning artifact images, matched real reference images, and paired generated reference images. Four aligned question types evaluate presence detection, semantic localization, spatial grounding, and evidence-grounded defect identification, while the reference splits test calibration and abstention when the annotated defect is absent. Across 20 VLMs, SalArt-VQA reveals failures that image-level detection accuracy hides: the strongest model reaches 99.37% detection recall on artifact images but answers all four artifact-side questions correctly on only 53.26% of images. Comparing artifact images with artifact-free references reveals a sensitivity-calibration tradeoff: sensitive models often make unsupported artifact claims, while conservative models avoid false alarms largely by missing real artifacts. These results show that high artifact detection accuracy alone does not imply grounded artifact understanding. SalArt-VQA exposes these hidden failure modes and provides a fine-grained evaluation of whether VLM artifact claims are supported by local visual evidence.

### 2. 方法论：SALART-VQA 基准
本文的核心思想是构建一个闭环式、细粒度的多选题（VQA）诊断基准，通过一系列对齐的问题，将VLM对伪影的分析链式拆解开来评估。关键设计如下：

*   **图像数据构建**：
    *   **伪影图像**：包含两种来源——**直接生成的伪影图像（Art-DG）** 和通过 **局部修复引入伪影的图像（Art-PG）**。后者通过编辑生成参考图像的局部（如手部）来引入一个可控的显著缺陷，而其余部分保持不变。
    *   **参考图像（用于校准和弃权测试）**：包括 **匹配的真实照片（Ref-Real）**和与Art-PG成对的**生成参考图像（Ref-PG）**。Ref-PG不保证全局无伪影，但保证不包含其成对Art-PG图像中的那个特定显著伪影，用于测试模型在特定缺陷缺失时能否正确弃权。
*   **问题类型设计（诊断链）**：
    针对同一个目标伪影，设计了四个独立、对齐的多选题，构成一个完整的诊断链条：
    1.  **存在性检测**：图像是否包含至少一个显著伪影？（是/否）
    2.  **语义定位**：哪个语义区域（如“右边那个人的右手”）最能体现最显著的伪影？（A/B/C/D/E选项）
    3.  **空间定位**：哪个边界框最能框定该伪影？（A/B/C/D/E选项，其中A-D框与Q2的语义区域对应）
    4.  **证据识别**：哪个选项最准确地**描述了**该伪影？（A/B/C/D/E选项，其中A-D描述与对应语义区域和缺陷假设关联）
    *   **关键设计**：Q2-Q4的A-D选项是**对齐的**，即同一字母（如A）指向同一个候选区域及其缺陷描述。所有问题的E选项均为“以上皆无”（弃权）。这种设计可以精确区分“检测到伪影但定位错误”、“定位正确但描述错误”等具体失败模式。
*   **评估指标**：除单题准确率外，核心关注`All Q1−4`（四题全对）和`All Q2−4`（下游三题全对）的图像级准确率，以及由此衍生出的失败模式分析。

### 6. 主要结论与发现
*   **高检测精度不等于扎实的理解**：最强模型Gemini 3.1 Pro虽然达到了99.37%的伪影检测召回率，但在能够回答全部四道题目的完整理解链上，其完全正确率仅为53.26%。图像级精度掩盖了大量的定位和证据推理失败。
*   **灵敏度-校准权衡（Sensitivity-Calibration Tradeoff）**：VLM普遍存在两种失败模式之一，且难以兼得。
    1.  **激进型模型**（如Gemini Pro）对伪影非常灵敏，但在无伪影的参考图像上容易提出“无根据的伪影主张”（难以弃权），导致特异性低。
    2.  **保守型模型**（如GLM-4.6V, GPT-5.4）在参考图像上校准良好（高特异性），但这主要是因为它们对真实伪影也极不敏感（低召回率），通过“一律说不”来避免误报。
*   **不同的瓶颈模式**：不同模型的失败模式各异。有的模型主要瓶颈在定位（能发现并描述对伪影，但指错位置），有的则主要瓶颈在检测本身，或是在不同的问题对（如语义定位 vs. 空间定位）之间存在显著矛盾。

### 7. 主要优点
*   **细粒度诊断能力**：将伪影理解分解为存在性、语义定位、空间定位和证据描述四个独立环节，能够精准定位模型失败的具体阶段，远超传统图像级评估的深度。
*   **精巧的对照设计**：通过引入匹配真实图像和成对生成参考图像，并统一设置“以上皆无”弃权选项，直接量化了模型的**校准与弃权能力**，这是当前评估中非常稀缺和重要的维度。
*   **高信度的人工标注**：采用闭集多选题和精确匹配评分，避免了开放式文本评估的模糊性。人工标注者能达到近乎完美的准确率，证明题目本身是明确可答的。
*   **全面的模型覆盖**：在零样本设定下评估了多达20个主流和前沿的VLM，结论具有普遍代表性。

### 8. 不足与局限
*   **受控环境与现实差距**：基准专注于单一、语言可描述的显著伪影，这有利于诊断但可能与真实世界中复杂、多伪影、或模糊不清的场景有所不同。论文作者承认这一点，认为这是深入研究所需的前提条件。
*   **闭集选项限制**：答案为固定的A-E，这虽然简化了评估，但模型的实际能力可能受限于选项的构造。一个在开放式描述中表现良好的模型，可能因选项干扰而失败。
*   **特定模型偏差风险**：虽然评估了大量模型，但结果仍局限于被测试的模型版本。不同提示词、不同API版本可能带来性能波动。论文通过在固定时间窗口、使用默认配置评估来缓解此问题。
*   **评估是诊断性而非因果性**：基准揭示了模型“在哪里”失败，但不能直接解释“为什么”失败（如究竟是感知、推理还是位置偏见问题），这个机制性的解释留待未来研究。
