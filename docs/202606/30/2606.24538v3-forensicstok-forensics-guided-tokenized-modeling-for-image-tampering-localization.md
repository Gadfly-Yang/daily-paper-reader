## 摘要
多模态大语言模型（MLLM）为取证任务提供了强大的推理能力，但现有方法利用外部分割解码器往往导致次优的定位效果。对拼接式流程的依赖在反向传播过程中引入了信息瓶颈，稀释了空间信号，并受到分割器语义先验的限制。为解决这些局限性，我们提出ForensicsTok，它将图像篡改定位重新定义为自回归序列生成任务。ForensicsTok直接生成具有空间基础的标记序列，无需中间监督即可实现精确的掩码预测。具体而言，我们引入了一种标记散布解码器（TSD），通过感知码本的代码平滑将标记映射为二值掩码，从而缓解了确定性去标记器带来的尖锐梯度。此外，为了捕捉多样化的篡改线索，我们提出了一种层次化专家融合（HEF）模块，该模块注入来自取证专家模型的多尺度特征。这种统一架构有效地弥补了标准MLLM中缺乏取证先验知识的不足。在六个基准测试上的大量实验表明，ForensicsTok相较于现有基于MLLM的基线方法有显著提升，并且略优于强大的取证专家基线方法，同时表现出对扰动更强的鲁棒性。

## Abstract
Multi-modal Large Language Models (MLLMs) offer powerful reasoning for forensic tasks, yet existing approaches utilizing exogenous segmentation decoders often suffer from suboptimal localization. The reliance on stitched pipelines introduces information bottlenecks during backpropagation, which dilutes spatial signals and is limited by semantic priors of the segmentor. To address these limitations, we propose ForensicsTok, which reformulates image manipulation localization as an autoregressive sequence generation task. ForensicsTok directly generates spatially grounded token sequences, enabling precise mask prediction without intermediary supervision. Specifically, we introduce a Token Splatting Decoder (TSD) to map tokens to binary masks via codebook-aware code smoothing, which mitigates sharp gradients from deterministic detokenizers. Furthermore, to capture diverse tampering clues, we propose a Hierarchical Expert Fusion (HEF) module that injects multi-scale features from a forensic expert model. This unified architecture effectively compensates for the lack of forensic priors in standard MLLMs. Extensive experiments on six benchmarks show that ForensicsTok substantially improves over existing MLLM-based baselines and slightly improves over strong forensic expert baselines, while exhibiting stronger robustness to perturbations.

## 二、方法论

### 2.1 整体框架
ForensicsTok将篡改定位建模为“令牌化掩码的自回归预测”：
- 图像和查询文本经视觉编码器与语言模型处理后，自回归生成文本与**定位令牌序列**。
- 定位令牌随后通过**令牌散布解码器（Token Splatting Decoder, TSD）**映射为二值篡改掩码。

### 2.2 令牌散布解码器（TSD）
**动机**：采用码本式去令牌器时，视觉上相似的局部掩码可能映射到相近的码本索引，但标准交叉熵损失将所有非目标码字视为正交，造成“全有或全无”的刚性监督，带来不稳定的梯度。

**解决方案**：
- 沿用现有码本式掩码令牌化方式（如HiMTok），但在监督端引入**码本感知标签平滑**：
  1. 对真实码字 \(y\)，在固定的码本 \(C\) 中计算其与所有码字的余弦相似度。
  2. 选取邻域大小 \(K\)，得到语义邻居集合 \(N_K(y)\)。
  3. 用温度缩放 softmax 为每个邻居码字分配平滑权重 \(w_k\)。
  4. 最终的 TSD 损失是硬目标损失与邻居损失加权的混合：
     \[
     \mathcal{L}_{\text{TSD}}(z,y) = (1-\epsilon)\,\mathcal{L}_{\text{CE}}(z,y) + \epsilon \sum_{k\in N_K(y)} w_k\,\mathcal{L}_{\text{CE}}(z,k)
     \]
  该损失仅依赖于固定的码本和真实标签，无需对相似度核进行求导，从而提供更加平滑的监督信号，稳定训练。

### 2.3 层次化专家融合（HEF）
**设计思想**：不同篡改类型依赖不同线索（如细微纹理、语义不和谐）。传统方法在视觉骨干**之后**进行特征拼接（后融合）会劣化取证线索，因为取证特征与语义特征异质且缺乏多尺度对齐。

**内部融合机制**：
- 冻结轻量级取证专家模型（SparseViT）作为固定特征提取器，提取浅层特征 \(E_s\)（纹理）和深层特征 \(E_d\)（语义不和谐）。
- 在视觉编码器的**每一个阶段 \(i\)** ，将专家特征与视觉特征 \(F_i\) 通过**注意力门控**进行融合：
  - 将 \(E_s\)、\(E_d\) 空间对齐后，与 \(F_i\) 通过可学习投影和 softmax 计算注意力权重 \(\alpha_i, \beta_i\)。
  - 更新特征：
    \[
    \hat{F}_i = F_i + \text{FFN}\big(\alpha_i \tilde{E}_s + \beta_i \tilde{E}_d\big)
    \]
- 修正后的特征继续前向传播，最终送入 LLM。

通过这种阶段式注入，模型能灵活地强调不同尺度、不同类型的取证线索。

### 2.4 训练目标
整体损失是三项的线性组合，且权重均设为1：
- \(\mathcal{L}_{\text{TSD}}\)：码本感知标签平滑损失。
- \(\mathcal{L}_{\text{mask}}\)：像素级二值交叉熵与 Dice 损失的组合。
- \(\mathcal{L}_{\text{HML}}\)：继承自HiMTok的层次化掩码约束损失。

## 六、主要结论与发现

- **直接生成令牌序列比依赖外部分割器更有效**：ForensicsTok 将定位重构为自回归令牌生成，消除了信息瓶颈与语义歧义，显著超越 FakeShield 和 SIDA。

## 七、优点

1. **任务重构新颖且有效**：将定位转化为自回归令牌生成，避免了外挂解码器的信息损失，使 MLLM 的输出能直接受空间标注监督。
2. **针对性解决两个核心痛点**：
   - TSD 利用固定码本的语义邻域进行软监督，优化更稳定；
   - HEF 通过阶段式门控融合，让MLLM 摄取多尺度取证线索，缓解了异质特征融合难题。
3. **实验设计完善、对比公平**：采用统一的训练池和评估协议，消融、融合策略、专家选择、鲁棒性等实验均覆盖，结论可信。

5. **兼顾检测与定位**：统一框架可同时完成篡改检测和区域定位，并展现了较强的实用鲁棒性。

## 八、不足与局限

1. **依赖高质量专家模型**：HEF 性能受所注入的专家质量影响较大，若专家特征差或不匹配，门控机制无法完全滤除噪声，增益可能消失（如 MVSS 集成的提升甚微）。
2. **效率仍远不及轻量专家**：虽然比 FakeShield 更快更轻，但 8.5B 参数、1.39s/图的速度在低延迟应用中仍不现实，无法取代 SparseViT 等快速专家模型。
3. **对强压缩退化不够稳定**：JPEG‑70% 下 F1 从 0.79 跌至 0.66，揭示了模型仍依赖细粒度取证痕迹，易受压缩破坏。
4. **缺乏文本解释性评估**：虽然论文提及文本输出潜力，但所有实验仅聚焦于掩码预测，未评估其生成的可解释文本质量。
5. **未公开训练算力信息**：训练时长、GPU 配置不详，难以估算实际训练成本。
6. **数据集覆盖的局限性**：训练池虽综合了多种篡改类型，但评估集仍偏重拼接和 copy‑move，真实世界社交媒体压缩和复杂合成场景可能更多样，泛化性尚需进一步检验。
