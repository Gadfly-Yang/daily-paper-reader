## 摘要
AI辅助图像编辑对金融、法律和身份档案的信任构成威胁。ACM MM 2026的GenText-Forensics挑战赛要求生成结构化取证报告，即在多语言文本为中心的伪造图像中整合检测、像素级定位和自然语言解释。我们提出SEED，一个包含三个组件的模块化系统。首先，基于相似性引导的流程通过多样化的合成伪造增强训练数据。其次，基于DINOv3并采用LoRA适配的单个ViT，同时执行检测和像素级定位，在保留预训练先验的同时最小化可训练参数。第三，一个演进式推理管线接收检测器的预测结果，并通过MLLM生成完整的取证报告，经过提议器-评估器循环迭代优化报告质量。SEED在GenText-Forensics挑战赛中排名第三。代码和数据可在https://github.com/KahimWong/GenText-Forensics-3rd-Place获取。

## Abstract
AI-assisted image editing threatens trust in financial, legal, and identity records. The GenText-Forensics Challenge at ACM MM 2026 addresses this by requiring structured forensic reports, in which integrating detection, pixel-level localization, and natural language explanation for multilingual text-centric forgery images. We present SEED, a modular system with three components. First, a similarity-guided pipeline augments training with diverse synthetic forgeries. Second, a single ViT, built on DINOv3 with LoRA adaptation, jointly performs detection and pixel-level localization while preserving pre-trained priors with minimal trainable parameters. Third, an evolving harness takes the detector's predictions and generates a complete forensic report via an MLLM, iteratively improved through a proposer-evaluator loop optimizing report quality. SEED ranked 3rd in the GenText-Forensics Challenge. Code and data are available at https://github.com/KahimWong/GenText-Forensics-3rd-Place.

## 方法论
### 1. 相似性引导的合成伪造数据生成
*   **核心思想**：利用训练好的区域选择模型与质量评估模型，自动从真实文档的干净图像中选取源-目标文本区域，生成五种操作类型（复制-移动、拼接、插入、修复、覆盖）的伪造样本。
*   **配对训练策略**：每个合成伪造样本与其原始干净图像构成 (clean, forged) 对，训练时以匹配对组织批次，迫使模型在同一优化步中对比同一文档的真实与篡改版本，增强判别能力。

### 2. 基于ViT的联合检测与定位模型
*   **骨干网络**：采用冻结的 **DINOv3 ViT‑L/16** 作为视觉基础模型，保留预训练的迁移先验。
*   **轻量适配**：通过 **LoRA**（rank = 1）仅对注意力层的 q、k、v、o 投影和 MLP 的上下投影进行低秩更新，其余参数冻结，以极少的可训练参数学习伪造特征。
*   **统一架构**：
    *   **检测分支**：在输入序列前添加 [CLS] 令牌，经所有 Transformer 块后送入线性分类头，输出图像级伪造概率 \(\hat{y}\)。
    *   **定位分支**：遵循 **EoMT** 结构，在最后 4 个 ViT 块前插入可学习查询令牌，其后接 **Mask2Former** 式掩码头。查询特征经 MLP 转换，密集特征经上采样后点积得到掩码logits，再通过双线性上采样和 sigmoid 获得像素级伪造概率图 \(\hat{P}\)。
*   **训练目标**：复合损失函数
    \[
    \mathcal{L} = \lambda_{CE}\mathcal{L}_{CE}(c, y) + \lambda_{BCE}\mathcal{L}_{BCE}(\hat{P}, Y) + \lambda_{Dice}\mathcal{L}_{Dice}(\hat{P}, Y)
    \]
    其中 \(\lambda_{CE}=1.0\)，\(\lambda_{BCE}=\lambda_{Dice}=5.0\)。

### 3. 演进式推理管线（Meta‑Harness）生成取证报告
*   **输入表示**：将检测器输出的伪造概率图叠加到原始图像上（红色mask覆盖），作为 MLLM 的视觉输入，使其显式感知可疑区域。
*   **自动化进化流程**：采用 **Meta‑Harness** 框架，无需人工提示工程：
    1.  **初始化**：编码代理根据接口规范生成 seed harness，包含遮罩绘制、边界框转换、提示构建、输出修复等模块。
    2.  **提议器‑评估器循环**：在固定的 50 样本搜索集上，每个候选 harness 通过基础 MLLM（Qwen3.5‑Flash）生成报告，计算解释质量（BERTScore F1）和报告质量（GPT‑4o‑mini 评委打分），保留帕累托前沿。提议器 LLM（GPT‑5.5）参考最佳 harness 的代码与失败案例，生成新一代候选方案，迭代 30 轮。
    3.  **最终选取**：搜索结束后，选择综合表现最佳的 harness 生成全部测试报告，其输出严格遵守 `[Conclusion]`, `[RISK_SCORE]`, `[GROUNDING]`, `[REASON]` 等标签的 Markdown 格式。

## 实验设计
*   **数据集**：
    *   **训练**：RealText‑V2 训练集（13,500 张，含 6,000 张真实、7,500 张伪造） + 合成伪造集（25,028 张，含五种操作类型）。
    *   **跨域测试**：ForensicHub 中的四个外部基准：T‑SROIE（扫描票据）、OSTF（自然场景文本）、TPIC‑13（场景文本编辑）、RTM（混合文档篡改）。所有测试样本被裁剪为 512×512。
*   **评测指标**：最终分数 \(S_{Fin}\) 整合了检测 F1、定位 mIoU、解释 BERTScore、报告 LLM‑Judge 评分，分别赋权 0.3, 0.4, 0.15, 0.15。
*   **对比方法**：实验主要围绕配置消融，未直接与大量外部 detector 对比，但通过改变 LoRA rank、训练步数、批大小、JPEG 增强、是否使用合成数据与配对策略、图像分辨率等来验证组件效用。

*   **训练设置**：AdamW 优化器，学习率由 \(3\times10^{-4}\) 余弦衰减至 \(1\times10^{-5}\)，权重衰减 \(1\times10^{-4}\)，总步数 5k，批大小 20。
*   **推理管线搜索**：Meta‑Harness 迭代 30 代，每代调用 MLLM（Qwen3.5‑Flash）和评判模型（GPT‑4o‑mini），计算开销主要体现在 LLM API 调用。

*   **覆盖范围**：涵盖检测、定位、解释三项子任务，考察了域内、域外、多语言等多种情形，实验较全面。

## 主要结论与发现
1.  **降低训练容量有利于跨域泛化**：更小的 LoRA rank、更少的训练步数、更小的批大小可避免模型过拟合训练集伪造模式，大幅提升在 T‑SROIE、OSTF 等跨域集上的定位和检测 F1。
2.  **注意力层适配对图像级检测至关重要**：仅适配 MLP 会使检测 F1 明显下降，而定位性能变化不大。
3.  **合成数据 + 配对训练的组合效能**：合成数据将平均定位 F1 提升 9%，检测 F1 提升 9%；在此基础上采用配对训练，可再额外提升检测 F1（约 4%），虽稍降定位性能但综合效益显著。
4.  **高分辨率输入改善边界精度**：分辨率从 512 提高到 1280 使像素 F1 相对提升 13‑14%，但代价是 6.25 倍的像素计算量，实际应用需权衡。
5.  **自动化报告优化切实有效**：Meta‑Harness 在无人工干预的情况下，30 轮迭代使解释 BERTScore 从 68.7 升至 72.4，报告评判分从 76.2 升至 79.8，并维持 98% 的格式合规率。

## 优点
*   **极简与高效**：仅用单个 ViT + 低秩适配便统一检测与定位，参数增量极少，保持基础模型的强大表征。
*   **训练策略新颖**：配对（clean, forged）批次构建直观且有效，强制对比学习，小成本换取检测增益。
*   **端到端自动化**：Meta‑Harness 彻底消除提示工程的人力投入，实现可复现的、有原则的报告生成优化。
*   **实验扎实**：多轴消融覆盖了从模型设计到训练超参再到推理后处理的完整链路，结论具有启发性。
*   **可解释性落地**：直接产出结构化的取证报告，弥补了以往只定位不提理由的空白。

## 不足与局限
*   **检测器尚有拟合风险**：尽管通过低秩适配缓解，实验中仍观察到模型对训练集特定模式的依赖，在极具挑战的域（如 RTM，平均检测 F1 仅 0.207）上效果有限。
*   **合成数据生成可扩展性**：当前合成方法依赖额外的区域选择模型，其质量直接影响伪造样本的真实性，且没有深入探讨不同伪造类型配比的影响。
*   **MLLM 幻觉**：报告生成可能产生不准确或逻辑错误的证据链，论文未评估幻觉率，未来需加强推理鲁棒性。
*   **计算成本**：高分辨率训练（1280px）消耗巨大，且 Meta‑Harness 需调用大量 LLM 服务，部署时延和成本未讨论。
*   **对比略显单一**：未与挑战赛中其他 Top 方案或同期代表性方法（如 TextShield-R1）直接对比，难以完全定位 SEED 的竞争力边界。
