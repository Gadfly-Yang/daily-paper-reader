## 摘要
多模态大语言模型（MLLMs）为取证任务提供了强大的推理能力，但现有利用外部分割解码器的方法通常存在定位不理想的问题。拼接式流程在反向传播中引入信息瓶颈，稀释了空间信号，并受限于分割器的语义先验。为解决这些局限，我们提出ForensicsTok，将图像篡改定位重新定义为自回归序列生成任务。ForensicsTok直接生成具有空间依据的令牌序列，无需中间监督即可实现精确的掩码预测。具体地，我们引入令牌散布解码器（TSD），通过码本感知的码平滑将令牌映射为二值掩码，从而缓解确定性去令牌化器带来的尖锐梯度。此外，为了捕捉多样化的篡改线索，我们提出层次化专家融合（HEF）模块，注入来自取证专家模型的多尺度特征。这一统一架构有效弥补了标准MLLMs中取证先验的缺失。在六个基准上的大量实验表明，ForensicsTok相比现有基于MLLM的基线有显著提升，相比强取证专家基线有轻微提升，同时对扰动表现出更强的鲁棒性。

## Abstract
Multi-modal Large Language Models (MLLMs) offer powerful reasoning for forensic tasks, yet existing approaches utilizing exogenous segmentation decoders often suffer from suboptimal localization. The reliance on stitched pipelines introduces information bottlenecks during backpropagation, which dilutes spatial signals and is limited by semantic priors of the segmentor. To address these limitations, we propose ForensicsTok, which reformulates image manipulation localization as an autoregressive sequence generation task. ForensicsTok directly generates spatially grounded token sequences, enabling precise mask prediction without intermediary supervision. Specifically, we introduce a Token Splatting Decoder (TSD) to map tokens to binary masks via codebook-aware code smoothing, which mitigates sharp gradients from deterministic detokenizers. Furthermore, to capture diverse tampering clues, we propose a Hierarchical Expert Fusion (HEF) module that injects multi-scale features from a forensic expert model. This unified architecture effectively compensates for the lack of forensic priors in standard MLLMs. Extensive experiments on six benchmarks show that ForensicsTok substantially improves over existing MLLM-based baselines and slightly improves over strong forensic expert baselines, while exhibiting stronger robustness to perturbations.

#### 2. 论文提出的方法论

- **核心思想**：将IMDL转化为由MLLM直接自回归预测一系列离散令牌，再利用预训练码本将这些令牌转换为二值掩码，实现端到端的、直接监督的像素级定位。同时，通过分层注入专家特征来增强视觉编码器对低层伪造痕迹的感知。

- **关键技术细节与流程**：
  - **整体架构（ForensicsTok）**：
    - 视觉编码器提取多尺度视觉特征，同时利用冻结的取证专家模型（SparseViT）提取浅层纹理特征 \(E_s\) 和深层语义痕迹特征 \(E_d\)。
    - **层次化专家融合（HEF）模块**：在视觉编码器的各个中间阶段，通过注意力门控机制自适应融合专家特征和原始视觉特征。公式如下：
      - 对齐尺度：\(\tilde{E}_s, \tilde{E}_d = \text{resize}(E_s, \text{size}(F_i)), \text{resize}(E_d, \text{size}(F_i))\)
      - 计算门控权重：\([\alpha_i, \beta_i] = \text{Softmax}\left(\frac{(W_i^q F_i)^\top [W_i^s \tilde{E}_s, W_i^d \tilde{E}_d]}{\sqrt{d}}\right)\)
      - 注入融合：\(\hat{F}_i = F_i + \text{FFN}(\alpha_i \tilde{E}_s + \beta_i \tilde{E}_d)\)
    - MLLM接收融合后的视觉特征和文本查询，自回归生成文本回复和“局部化令牌”（离散码索引序列）。
    - **令牌散布解码器（TSD）**：将生成的码索引序列通过冻结的码本进行最近邻查找，得到对应的嵌入向量，再解码为二值掩码。为了解决标准独热标签训练时码本中语义相近的码被硬性惩罚的问题，提出**码本感知标签平滑**，将一小部分概率质量从真值码重新分配给其在码本中的语义邻居，损失函数为：
        \[
        L_{\text{TSD}}(z, y) = (1 - \epsilon) L_{\text{CE}}(z, y) + \epsilon \sum_{k \in N_K(y)} w_k L_{\text{CE}}(z, k)
        \]
        其中 \(N_K(y)\) 是语义邻居集合，\(w_k\) 由温度缩放的余弦相似度计算得到。
  - **训练目标**：联合损失 \(L_{\text{total}} = \lambda_{\text{TSD}} L_{\text{TSD}} + \lambda_{\text{mask}} L_{\text{mask}} + \lambda_{\text{HML}} L_{\text{HML}}\)。其中，\(L_{\text{mask}}\) 结合二元交叉熵和 Dice 损失，\(L_{\text{HML}}\) 继承自 HiMTok 的分层掩码损失。
