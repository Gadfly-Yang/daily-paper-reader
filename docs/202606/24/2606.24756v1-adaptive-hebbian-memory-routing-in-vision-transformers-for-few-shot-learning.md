## 摘要
小样本图像识别要求模型从少量有标签的支持集中适应新类别。赫布快速权重记忆可以在一个情节内提供临时的关联信息，但固定的记忆行为可能并不适用于每个小样本任务。在这项工作中，我们提出了面向小样本视觉Transformer的自适应赫布路由。该方法使用轻量级MLP路由器来控制赫布记忆的贡献、记忆更新的强度以及对来自支持集特征的先前记忆的保留。我们研究了自适应放置、自适应可塑性和全自适应赫布路由。实验使用ViT-Small、DeiT-Small和Swin-Tiny，在Omniglot、CIFAR-FS以及从CIFAR-FS到Omniglot的跨域迁移上，进行5-way 1-shot评估。在直接的Swin对比中，固定和自适应的赫布变体使用相同的记忆位置。自适应可塑性将固定赫布结果从96.74%提升到96.92%，而全自适应路由取得了最佳结果96.94%。相对于固定赫布Swin，全自适应Swin模型还将推理时间从16.51毫秒减少到14.05毫秒。在CIFAR-FS上，自适应变体在所有三个骨干网络上均提升了性能，多样本评估表明，随着支持样本数量的增加，这些增益仍然有用。这些结果表明，自适应可塑性和自适应记忆激活可以改进小样本Transformer的表征，超越固定的赫布行为。

## Abstract
Few-shot image recognition requires models to adapt to new classes from a small labeled support set. Hebbian fast-weight memory can provide temporary associative information during an episode, but fixed memory behavior may not be appropriate for every few-shot task. In this work, we propose Adaptive Hebbian Routing for few-shot Vision Transformers. The method uses a lightweight MLP router to control the contribution of Hebbian memory, the strength of memory updates, and the retention of previous memory from support-set features. We study Adaptive Placement, Adaptive Plasticity, and Fully Adaptive Hebbian Routing. Experiments use ViT-Small, DeiT-Small, and Swin-Tiny under 5-way 1-shot evaluation on Omniglot, CIFAR-FS, and cross-domain transfer from CIFAR-FS to Omniglot. In the direct Swin comparison, fixed and adaptive Hebbian variants use the same memory location. Adaptive Plasticity improves the fixed Hebbian result from 96.74\% to 96.92\%, while Fully Adaptive Routing achieves the best result at 96.94\%. The fully adaptive Swin model also reduces inference time from 16.51 ms to 14.05 ms relative to fixed Hebbian Swin. On CIFAR-FS, adaptive variants improve performance across all three backbones, and the multi-shot evaluation shows that these gains remain useful as the number of support examples increases. These results show that adaptive plasticity and adaptive memory activation can improve few-shot Transformer representations beyond fixed Hebbian behavior.

## 1. 核心问题与研究动机
- **核心问题**：小样本图像识别要求模型在每 episode 仅凭极少量有标签支持图像就快速适应新类别。赫布（Hebbian）快速权重记忆可为一 episode 内提供临时关联信息，但传统的**固定记忆行为**（固定的激活程度、更新强度和衰减率）无法根据具体任务动态调整，导致记忆利用低效甚至有害。
- **整体含义**：提出一种**自适应赫布路由**机制，让记忆的贡献程度、写强度与历史保留等行为随 support set 特征变化，使得 Transformer 在小样本条件下的表征生成更具任务针对性，从而提升精度并降低计算开销。

## 2. 方法论
- **核心思想**：为选定的骨干网络位置插入 Hebbian 快速权重记忆模块，并配备一个轻量的 **MLP 路由器**，该路由器以当前 episode 的支持集特征为条件，输出三个控制标量：记忆输出门控 \(g_l\)、塑性率 \(\eta_l\) 和记忆衰减因子 \(\lambda_l\)。
- **路由器工作流程**：
  1. 从某一层取出支持图像的 token 特征，沿图像和 token 维度取均值，得到 episode 级摘要向量 \(z_l\)。
  2. 通过一个两层 MLP（GELU 激活 + LayerNorm），输出三个标量并经 sigmoid 缩放。
  3. 这些标量分别控制：\(g_l\) 调节 Hebbian 读出的残差比例；\(\eta_l\) 控制 associative matrix 的更新强度（上限 0.15）；\(\lambda_l\) 控制旧记忆保留程度。
- **记忆更新与读出**：
  - 输入 token 线性投影为 K, V, Q。
  - 关联矩阵更新: \(A = \text{clip}(K^\top V/\sqrt{T}, -\delta, \delta)\)。
  - 记忆矩阵更新: \(M \leftarrow \lambda_l M + \eta_l A\) (Frobenius 范数归一化)。
  - 读出: \(R = Q M\)，经内部可学习特征门控、归一化后，以 \(g_l\) 加权残差加到原始表征。
  - 每 episode 开始时记忆矩阵重置。
- **三种自适应变体**：
  - **自适应放置 (Adaptive Placement)**：仅预测 \(g_l\)，塑性率和衰减仍为固定可学习参数。
  - **自适应塑性 (Adaptive Plasticity)**：仅预测 \(\eta_l\) 和 \(\lambda_l\)，记忆通路保持全激活。
  - **全自适应路由 (Fully Adaptive Hebbian Routing)**：同时预测 \(g_l\), \(\eta_l\), \(\lambda_l\)。
- **骨干集成**：
  - ViT‑Small 和 DeiT‑Small：在 Transformer blocks 3, 6, 9, 12 后插入自适应 Hebbian 模块。
  - Swin‑Tiny：固定与自适应变体使用**相同记忆位置**，以隔离自适应控制的效果。

## 3. 实验设计
- **数据集与场景**：
  - Omniglot（字符识别，从零训练）。
  - CIFAR‑FS（通用物体识别，ImageNet 预训练微调）。
  - 跨域迁移：CIFAR‑FS → Omniglot，无目标域微调。
- **评估协议**：
  - 主实验：**5‑way 1‑shot** episodic 分类，基于原型网络 (Prototypical Networks)，使用欧氏距离。
  - 多 shot 评估：CIFAR‑FS 上 5‑way 1/3/5/10‑shot，考察增益的持久性。
- **对比方法**（每个骨干均比较）：
  - Base（无 Hebbian 记忆）。
  - Fixed Hebbian（固定记忆行为）。
  - Adaptive Placement / Plasticity / Fully Adaptive。
- **关键原则**：ViT/DeiT 的 Fixed Hebbian 采用密集插入，而自适应用 4 个选定位置；Swin 上固定与自适应使用**完全相同的插入位置**。

## 6. 主要结论与发现
- **Swin 上直接对比**（相同位置）：
  - 自适应放置（仅调整贡献度）未能超越固定 Hebbian (96.63% vs 96.74%)。
  - **自适应塑性**将固定 Hebbian 的准确率从 96.74% 提升到 **96.92%**。
  - **全自适应路由**取得最高准确率 **96.94%**，同时推理时间从 16.51 ms 减至 14.05 ms。
- **ViT 和 DeiT**：密集固定 Hebbian 严重损害性能（Omniglot 上从 95.42% 跌至 89.99%），三个自适应变体均将性能恢复至接近或超过原始基线的水平，且参数更少、推理更快。
- **CIFAR‑FS 上**：所有三个自适应变体在所有骨干上均大幅超越固定 Hebbian（例如 ViT 从 72.58% 提升至 88.59%），且随着 support shot 增加（1→10），自适应变体的优势持续保持。
- **跨域迁移**：效果混合，Swin 的全自适应最佳 (74.30%)，DeiT 的自适应放置最佳 (77.03%)，ViT 的固定 Hebbian 仍保持最高；说明自适应控制不能完全消除域偏移的影响。
- **效率**：自适应变体通常带来更低的参数开销（因使用更少模块）和更快的推理速度，尤其在 ViT/DeiT 上效果显著。

## 7. 优点
- **轻量自适应**：MLP 路由器极轻量（隐藏维度 = 输入维度的 1/8，最少 16），额外参数量极小。
- **无需变更记忆位置即获提升**：Swin 对比证明，仅通过让记忆行为自适应当前 episode，即可从已知好位置中榨取更多性能。
- **恢复能力**：对 ViT/DeiT 这种原本因密集固定 Hebbian 而恶化的架构，自适应控制能“挽救”记忆插入，使之变得有用且高效。
- **实用效率**：在提升准确率的同时，通常降低推理延迟，适合部署。
- **多样性验证**：多个异构骨干、多个数据集、多 shot、跨域迁移，结论具有较广的适用范围。

## 8. 不足与局限
- **跨域迁移的不一致性**：ViT 在跨域时固定 Hebbian 仍最佳，说明自适应路由的优势可能依赖于源域表示性质，泛化机理尚不明确。
- **数据集规模**：仅在相对小型的 Omniglot 和 CIFAR‑FS 上验证，未在更具挑战的大规模小样本基准（如 miniImageNet, tieredImageNet）或更真实的跨域场景上测试。
- **骨干网络规模有限**：实验仅使用 ViT‑Small/DeiT‑Small/Swin‑Tiny，未扩展到更大或更新的视觉骨干（如 ViT‑Large, Swin‑Base 等）。
- **路由器设计简单**：仅使用平均池化和浅层 MLP，可能丢失空间或 token 之间的信息；更复杂的 episode 编码器（如 Transformer 或集合函数）未被探索。
- **自适应变量独立**：当前三个变量分别由独立输出头预测，未考虑它们之间的潜在交互结构。
- **仅修改特征提取器**：分类仍用简单原型方法，未联合优化分类器与记忆的自适应。
