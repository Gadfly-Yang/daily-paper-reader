## 摘要
我们提出了MM++（多层马氏距离++），一种完全无监督、严格事后且尺度不变的分布外检测框架。为解决尺度不变性与层次表达能力之间的权衡，MM++构建了一个有原则的联合特征空间。它首先通过测量熵密度下降来识别区分性的中间层，熵密度下降标志着显著语义压缩的边界。通过将这些选定层与最终表示融合，该框架捕获了潜在的跨层相关性，同时减轻了早期层的噪声。关键的是，Ledoit-Wolf正则化的共享协方差矩阵稳定了这个统一空间，从而实现了可靠的距离估计。MM++无需辅助OOD数据、分类器微调或架构修改，在不同架构上对于近OOD和远OOD检测都能提供稳健的性能。

## Abstract
We introduce MM++ (Multilayer Mahalanobis++), a fully unsupervised, strictly post-hoc, and scale-invariant framework for Out-of-Distribution (OOD) detection. To address the trade-off between scale invariance and hierarchical expressivity, MM++ constructs a principled joint feature space. It first identifies discriminative intermediate layers by measuring entropy density drops, which mark the boundaries of sharp semantic compression. By fusing these selected layers with the terminal representation, the framework captures latent cross-layer correlations while mitigating early-layer noise. Crucially, a Ledoit-Wolf regularized tied covariance matrix stabilizes this unified space, enabling reliable distance estimation. Requiring no auxiliary OOD data, classifier fine-tuning, or architectural modifications, MM++ delivers robust performance across distinct architectures for both near- and far-OOD detection.

# 论文深度分析：MM++ — 无监督尺度不变多层OOD检测

## 1. 研究动机与核心问题

深度神经网络在开放世界中部署时，常对分布外（Out-of-Distribution, OOD）样本产生过度自信的预测，这在高风险领域（如医疗诊断、自动驾驶）中会引发严重安全隐患。该现象的深层原因之一是**神经坍缩**（neural collapse）现象：训练过程中，网络会将分布内（ID）样本的表示压缩到高度结构化、低维的类中心，抑制了类内变异性。虽然这提升了分类精度，但也降低了表示的多样性，导致OOD样本容易被投影到ID类结构附近，从而产生过度自信。

现有后处理方法面临两大挑战：
- **单层方法**（如Mahalanobis++）仅操作于终端的倒数第二层，虽引入尺度不变性但无法捕获中层结构线索，对近OOD检测能力有限。
- **多层方法**（如Mahalanobis、X-Mahalanobis）虽引入中间层，但**将各层表示视为独立边际分布**，通过加性融合得分，丢弃了跨层条件依赖，无法检测“层级不一致性”——即异常样本在单层看似符合ID，但违反了层间应有的演化轨迹。此外，这些方法往往需要代理OOD验证集或分类器微调，违反了严格的后处理设定。

因此，论文的核心问题是：**如何在完全无监督、严格后处理且保持尺度不变的条件下，有效融合多层特征信息，实现对近OOD和远OOD的稳健检测？**

## 2. 方法论：MM++框架

MM++框架通过三个关键组件解决了上述挑战：

### 2.1 熵密度引导的层选择（Entropy Density Drop）

- 对每一层`l`的类内协方差矩阵（经过Ledoit-Wolf收缩）进行特征值分解，计算其归一化特征谱的**香农熵** `H_l`。
- 定义**熵密度** `ρ_l = H_l / D_l`（单位维度的熵），使其成为尺度不变的表示丰富度度量。
- 计算相邻层间的**熵密度下降** `Δ_l = ρ_{l-1} - ρ_l`，一个大的正`Δ_l`标志着层`l`处发生了强烈的语义压缩——这是最具判别性几何结构的边界。
- 始终锚定倒数第二层`L`，再从其余层中选择`Δ_l`最大的`K-1`层（且`Δ_l > 0`）作为活跃层集`K`。

### 2.2 跨层拼接融合（Concatenated Fusion）

- 将选定层的`ℓ₂`归一化特征向量直接拼接成一个统一表示：
  ```
  ϕ(x) = [h̃_{l1}(x); h̃_{l2}(x); ...; h̃_{lK}(x)] ∈ ℝ^{ΣD_l}
  ```
- 该融合是**无损的**（保留每层完整信息），且**架构无关**（无需显式聚合权重），缩放贡献由后续的**联合精度矩阵**隐式学习。

### 2.3 联合马氏++距离与Ledoit-Wolf收缩

- 在拼接空间上计算类条件均值`μ̂_c^K`和共享协方差矩阵`Σ̂^K`。
- 应用**Ledoit-Wolf收缩**获得良态协方差矩阵：
  ```
  Σ̂_{K,shrink} = (1-γ)Σ̂^K + γ·[Tr(Σ̂^K)/D_K]·I
  ```
  其中收缩系数`γ`是从ID数据中解析推导的（最小化期望均方误差）。
- 最终OOD分数为拼接空间中的负最小马氏++距离：
  ```
  S_{MM++}(x) = -min_c (ϕ(x)-μ̂_c^K)ᵀ Σ̂^{-1}_K (ϕ(x)-μ̂_c^K)
  ```
- 该联合精度矩阵的**对角块**捕获层内协方差，**非对角块**编码跨层协方差，能够检测出单层看似正常但不满足跨层演化动态的异常样本——这是加性融合无法做到的。

MM++唯一的超参数是`K`（融合层数），在小值（如`K=2`）下即可获得最佳性能。

## 6. 主要结论与发现

- **多层融合显著优于单层**：MM++在长尾场景下平均AUROC达83.91%，在近OOD检测上（ImageNet-C、-ES、-R、-V2）一致超越所有基线。
- **拼接融合+联合精度矩阵优于加性融合**：通过建模跨层协方差，MM++能检测层级不一致性，而传统加性融合无法做到。
- **Ledoit-Wolf收缩在拼接空间中至关重要**：当`K>1`时，拼接后的高维空间极易病态，收缩估计带来了8.26% AUROC和17.5% FPR95的显著提升（表3）。
- **锚定倒数第二层是必要的**：仅依靠熵密度选层而不包含终端的变体性能大幅下降。
- **小`K`值足够**：`K=2`或`K=3`即可获得最佳性能与效率的平衡。
- **架构无关性**：在ViT、Swin-T、ConvNeXt-T、EVA02上均表现稳定，而X-Mahalanobis因依赖同质变换器特征而无法应用于Swin-T和ConvNeXt-T。

## 7. 优点

- **完全无监督与严格后处理**：无需任何代理OOD数据、分类器微调或架构修改，仅用ID训练数据即可。
- **尺度不变性**：通过`ℓ₂`归一化消除特征量级偏差，适用于不同架构和层次。
- **原理驱动的层选择**：熵密度下降提供了信息论的解释，避免了启发式的方差加权。
- **统一的联合建模**：拼接融合+联合精度矩阵的范式超越了传统的独立层得分聚合。
- **计算效率**：校准仅需数十秒，在线推理延迟极低（0.002ms），内存占用小（6KB），远超需要微调的方法。
- **实验全面性卓越**：涵盖4种架构、30+模型变体、平衡与长尾ID、近远OOD的完整评估矩阵，消融设计严密。

## 8. 不足与局限

- **对预训练表示质量的依赖**：作为严格后处理方法，MM++的性能受限于预训练网络的特征几何结构。当语义压缩不明显（`Δ_l ≤ 0`）时，中间层可能无法提供有价值的补充信息，此时MM++退化为单层检测器。
- **超参数`K`的性能抖动**：从`K=1`到`K=2`提升显著，但`K=3`可能出现短暂下降（图4），反映了信息冗余与统计噪声的权衡——虽然这一点在论文中被明确讨论并视为可预期的行为。
- **扩展至密集预测任务的挑战**：MM++目前针对图像分类设计，要在目标检测、语义分割等密集预测任务上工作，需要对空间局部化的内在维度进行估计，这仍是未解决的开放问题。
- **非单调熵密度带来选择的不确定性**：在结构性扩展（如通道上采样）或注意力混合层中，`Δ_l`可能为负，MM++需排除这些层（`Δ_l ≤ 0`），但在某些架构中这可能导致可选中间层较少。
- **DeiT3上的收益较小**：在强数据增强（MixUp、CutMix）和正则化训练的DeiT3模型上，MM++的提升有限，因为中间层与最终表示已高度对齐，多层信息冗余度较高。
