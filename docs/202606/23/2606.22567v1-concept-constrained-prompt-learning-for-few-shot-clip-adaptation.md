## 摘要
少样本提示学习是将CLIP适应下游任务的有效策略，但仅优化类别提示可能会过拟合基类监督，削弱对未见类的迁移能力。我们提出概念约束的提示学习（CCPL），这是一个轻量级正则化框架，将可学习的类别提示锚定到冻结的概念级文本原型，而不更新CLIP编码器。CCPL学习一组共享的上下文token，通过附加类别名称实例化类别提示，并从类别级概念库构建冻结的概念原型。训练期间，文本空间余弦一致性目标将可学习的类别提示嵌入与冻结的概念原型对齐；概念dropout通过防止对固定概念列表的过度依赖提供额外的正则化。推理时，CCPL可选地使用可控的集成权重α融合类别提示logits和概念原型logits。我们的默认配置使用文本空间概念正则化λ=0.5，概念dropout p=0.3和弱概念引导融合（α=0.1），没有基于KL的预测一致性项。在相同的自动生成的回退划分上的实验表明，与CoOp相比，CCPL在DTD（+0.6）和EuroSAT（+2.9）上提高了基类到新类的调和平均数，同时在OxfordPets上接近中性（-0.1）。消融实验表明文本空间概念正则化一直是有益的，而最佳的概念引导推理强度取决于数据集和协议。这些结果表明，当概念原型与数据集的语义自然对齐时，概念约束最为有效，并指出现有边界条件为细粒度类别。代码发布于：https://github.com/richael-sang/concept-constrained-prompt-learning。

## Abstract
Few-shot prompt learning is an effective strategy for adapting CLIP to downstream tasks, but class-only prompt optimization can overfit base-class supervision and weaken transfer to unseen classes. We propose Concept-Constrained Prompt Learning (CCPL), a lightweight regularization framework that anchors learnable class prompts to frozen concept-level text prototypes without updating CLIP encoders. CCPL learns a set of shared context tokens, instantiates class prompts by appending class names, and constructs frozen concept prototypes from a class-level concept bank. During training, a text-space cosine consistency objective aligns learnable class-prompt embeddings with frozen concept prototypes; concept dropout provides additional regularization against over-reliance on fixed concept lists. At inference, CCPL optionally fuses class-prompt logits with concept-prototype logits using a controllable ensemble weight alpha. Our default configuration uses text-space concept regularization lambda = 0.5, concept dropout p = 0.3 and weak concept-guided fusion (alpha = 0.1), with no KL-based prediction consistency term. Experiments under identical automatically-generated fallback splits show that CCPL improves the base-to-new harmonic mean on DTD (+0.6) and EuroSAT (+2.9) compared with CoOp, while remaining near-neutral on OxfordPets (-0.1). Ablations indicate that text-space concept regularization is consistently beneficial, while the best concept-guided inference strength is dataset- and protocol-sensitive. These results suggest concept constraints are most effective when concept prototypes align naturally with dataset semantics, and identify fine-grained categories as a current boundary condition. The code is released at: https://github.com/richael-sang/concept-constrained-prompt-learning.

- **问题背景**：少样本提示学习（如CoOp）在适应CLIP时，仅优化类别提示容易过拟合基类标注，导致对未见过的新类泛化能力下降，破坏CLIP原有的开放词汇语义结构。

- **整体含义**：提出一种轻量级正则化框架CCPL，利用预先构造的概念短语作为冻结的文本空间原型，在训练中对可学类别提示施加语义对齐约束，以在保持基类性能的同时提升新类迁移能力。

### 2. 方法论
- **核心思想**：将可学的共享上下文token与冻结的概念级文本原型对齐，通过文本空间余弦一致性损失进行正则化；同时引入概念dropout防止过度依赖特定概念；推理时可选地用可控权重α融合类别提示logits和概念原型logits。
- **关键技术细节**：
  - **类别提示参数化**：学习一组共享的上下文token（M=16），对每一类附加类别名称形成提示，通过冻结的CLIP文本编码器得到归一化的文本嵌入 \( \mathbf{t}_c^{\text{cls}} \)。
  - **概念库与原型构建**：从手工编制的概念库中为每个类别提取多个描述性短语（如EuroSAT“森林”对应“密集树冠”“林地”等），通过冻结文本编码器提取嵌入并平均，得到归一化的概念原型 \( \mathbf{t}_c^{\text{con}} \)。
  - **概念dropout**：训练时以概率 \( p_{\text{drop}}=0.3 \) 随机丢弃概念短语（保证至少保留一个），计算dropout后的概念原型作为正则化目标，提升鲁棒性。
  - **文本空间正则化**：对基类计算可学提示嵌入与（dropout后）概念原型的余弦一致性损失：  
    \[
    \mathcal{L}_{\text{text}} = \frac{1}{|C_{\text{base}}|} \sum_{c \in C_{\text{base}}} \left( 1 - \cos\left( \mathbf{t}_c^{\text{cls}}(\theta), \mathbf{t}_c^{\text{con}} \right) \right)
    \]
    仅作用于基类。总损失为交叉熵损失与加权正则项之和：\( \mathcal{L} = \mathcal{L}_{\text{ce}} + \lambda_{\text{text}} \mathcal{L}_{\text{text}} \)，默认 \( \lambda_{\text{text}}=0.5 \)。
  - **概念引导推理**：测试时计算概念原型logits \( \mathbf{z}^{\text{con}} \)，与可学提示logits \( \mathbf{z}^{\text{cls}} \) 按权重α融合：  
    \[
    \mathbf{z} = (1-\alpha) \mathbf{z}^{\text{cls}} + \alpha \mathbf{z}^{\text{con}}
    \]
    默认 \( \alpha=0.1 \)（弱融合）。α越大，越依赖冻结概念，带来基类和新类之间的权衡。
- **训练流程**：仅更新共享上下文token，CLIP的图文编码器完全冻结；新增可训参数仅8192个（CLIP ViT-B/16总参数量约1.5亿的0.005%）；概念原型一次性预计算，训练期间无额外参数更新。

### 6. 主要结论与发现
- CCPL在纹理（DTD）和场景（EuroSAT）数据集上能有效提升基类到新类的调和平均数（+0.6和+2.9），其中EuroSAT的提升主要来自新类准确率的大幅增长（+4.3pp）。
- 在细粒度宠物品种（OxfordPets）上性能几乎无变化甚至稍有下降，表明概念约束并非对所有任务均有益。
- 文本空间概念正则化对性能提升起到一致的正向作用；概念引导推理权重α会带来基类与新类的权衡，最佳α值因数据集和协议而异。
- 当概念短语与数据集的视觉属性自然对齐（如场景级属性）时，概念约束最为有效；而基于简单模板的概念对细粒度类别可能不具备足够的判别性。

### 7. 优点
- **轻量且即插即用**：无需增加可训参数（仅共享上下文token），不影响CLIP编码器，训练开销极低。

- **可调的推理策略**：通过融合权重α提供了一种无需重新训练即可控制泛化倾向的机制，增加了方法的灵活性。
- **边界条件分析清晰**：主动指出了在细粒度分类上的失效情况，并讨论了概念质量、数据集语义等影响因素，避免了过度推广。
